## 전체 시리즈 — 가입부터 시작하는 여정 순서 (총 16편)

시청·녹화 권장 순서. **모든 여정은 가입에서 출발**하고, 각 역할 화면이 연결된 하나의 시연 스토리로 이어진다.

| 순서 | 편 | 제목 | 여정 단계 |
|---|---|---|---|
| 1 | **P1** | 업체 — 가입 신청 (계정·업체 정보·서비스 지역·사업자 인증) | 가입 |
| 2 | **T1** | 기사 — 가입 신청 (근로 형태·본인인증은 **화면 소개 후 나레이션으로 안내하고 넘어감**). 가입 즉시 승인·자동 로그인되므로 **T2로 바로 연결** | 가입 |
| 3 | **A4** | 관리자 — **업체** 가입 신청 심사: 서류 확인·승인·거절 (기사는 심사 대상이 아님) | 심사 |
| 4 | **A5** | 관리자 — 직접 등록(업체·기사)과 정보 수정 | 심사 |
| 5 | **T2** | 기사 — 첫 로그인과 근로확인서 서명 | 온보딩 |
| 6 | **A6** | 관리자 — 기사 관리·근로확인서 확인·인쇄 | 온보딩 |
| 7 | **A7** | 관리자 — 알(크레딧) 충전·정정 ★ | 온보딩 |
| 8 | **A1** | 관리자 — 로그인과 관제탑 대시보드 | 접수 |
| 9 | **A2** | 관리자 — 접수 상세 확인과 수동 배정 | 배정 |
| 10 | **P2** | 업체 — 배정 수락, 출동, 완료 처리 | 수행 |
| 11 | **T3** | 기사 — 배정 수락~완료와 정산·성과 확인 | 수행 |
| 12 | **A3** | 관리자 — 배정 회수·접수 취소·만족도 조사 | 예외 처리 |
| 13 | **P3** | 업체 — 알·수수료·내 정보 관리 | 정산 |
| 14 | **A8** | 관리자 — 정산: 수수료 지급과 월 집계 | 정산 |
| 15 | **A9** | 관리자 — 분석 4종과 순환 현황 | 운영 |
| 16 | **A10** | 관리자 — 설정 | 운영 |

각 영상 공통 구조(매뉴얼 best practice): ① 이 영상에서 배우는 것 → ② 진입 경로 → ③ 단계별 실연 → ④ 결과 확인 포인트 → ⑤ 주의사항/실수 방지

## 역할별 가입 체크리스트 (P1·T1)

### P1 업체 가입 (`/partner/signup`)
- [ ] 진입: 홈 → 업체 포털 → 가입 신청
- [ ] 계정: 로그인 아이디 + 중복 확인 버튼·비밀번호·비밀번호 확인(표시 토글)
- [ ] 업체 정보: 업체명·전화번호·상세 주소
- [ ] 서비스 가능 지역: 지역 추가(복수)
- [ ] 사업자 인증: 사업자등록번호·사업자등록증/전기공사업 등록증 첨부
- [ ] 추천인(선택): 전화번호 입력 → 확인 조회, "가입 시에만 지정 가능" 안내
- [ ] 가입 신청하기 → 승인 대기 안내 → 관리자 승인 후 로그인 가능 (A4로 연결)

### T1 기사 가입 (`/tech/signup`)
- [ ] 진입: 홈 → 기사 포털 → 가입 신청
- [ ] 계정: 아이디 + 중복 확인·비밀번호·확인
- [ ] 근로 형태: 일일 근로자(8시간 단위) vs 상시 근로자(09~18시)
- [ ] 성명·전화번호 → **본인인증 버튼: 창이 뜨는 것까지 보여주고 "통신사 인증을 진행하세요" 나레이션 후 다음 단계 설명으로 전환** (자동화 불가·실인증 생략)
- [ ] 상세 주소·서비스 가능 지역 (거주 시/도를 처음 고르면 서비스 지역에 그 시/도가 자동으로 1건 추가됨)
- [ ] 추천인(선택)
- [ ] 약관·개인정보 동의 체크 → 가입 신청하기
- [ ] **승인 대기 없음** — "가입이 완료되었습니다 / 자동으로 로그인되었습니다" 화면과 `근로확인서 작성하러 가기` 버튼을 보여주고 **T2로 연결** (관리자 심사 단계가 없으므로 A4로 넘기지 않는다)

## §1 로그인·공통 (A1)

- [ ] 로그인: 아이디·비밀번호 입력 → 로그인 버튼 (빈 값이면 비활성)
- [ ] 로그인 오류 대응: 아이디/비밀번호 불일치 안내
- [ ] 상단 메뉴 9종 소개: 대시보드·업체 관리·전기기사 관리·순환 현황·정산·정산 집계·분석(하위 4)·설정·로그아웃
- [ ] 업체 관리 메뉴의 승인 대기 숫자 배지 의미
- [ ] 분석 드롭다운: 현황·지도·설문·평점
- [ ] 로그아웃 (공용 PC 주의)

## §2 대시보드(관제탑) (A1)

- [ ] 요약 카드: 오늘 접수(★시간대 스파크라인)·배정 대기(★확인 칩, 클릭→탭 전환)·진행중·완료/취소
- [ ] 긴급 미완료 카드 → 클릭 이동
- [ ] 분석 보기 카드 → 분석 현황 이동
- [ ] 상태 탭 5종: 전체/배정대기/배정됨/진행중/완료·취소 (+건수 표시)
- [ ] 접수 검색: 접수번호·이름·전화·내용
- [ ] 시각 열 정렬 토글
- [ ] "확인요망" 빨간 표시 의미(빨간 행 배경)
- [ ] 행 클릭 → 우측 SELECTED REQUEST 요약 패널(상태·배정 이력 요약·설문 여부) → 상세 열기
- [ ] 자동 갱신(폴링) 안내 — 새 접수는 자동 반영

## §3 접수 상세 (A2·A3)

### 3.1 기본 정보 (A2)
- [ ] 헤더: 접수번호·긴급도 배지·상태 배지
- [ ] 고장 내용·접수 시각·고객명·전화(탭하면 전화 연결)·주소
- [ ] ★사진 갤러리 — 고객 첨부 사진 확인/원본 보기
- [ ] ★음성 접수 — 녹음 재생 + 자동 변환 텍스트 표시
- [ ] 지도에서 보기(좌표 있을 때) / 주소 미확인 표시

### 3.2 배정 추천 순위 (A2)
- [ ] ★근거 사슬 안내: 거절이력 → 지역 → 알 보유량 → 30일 배정 → 평균 별점 → 거리
- [ ] 후보 카드 읽는 법: 업체/전기기사 구분·거리·알·30일 배정·평점
- [ ] ★1순위 "자동배정 예정" 배지 / 순위 열세 사유 표시(예: "알 보유량에서 뒤짐")
- [ ] ★자동배정 카운트다운("자동배정까지 mm:ss", 워커 30초 오차 주석) / 자동배정 꺼짐 표시 / 후보 없음 안내

### 3.3 수동 배정 (A2)
- [ ] 배정 버튼 → 확인 모달("~에게 배정할까요? 안내 문자 발송") → 확정
- [ ] 상태 배정됨 전환 + 배정 이력 생성(응답 대기) 확인

### 3.4 배정 이력 (A2)
- [ ] 이력 행: 대상·응답 상태(응답 대기/수락/거절+사유)·수동/자동배정 구분

### 3.5 배정 회수 (A3)
- [ ] 업체 응답 대기 중일 때만 표시 — 회수 → 배정대기 복귀
- [ ] 회수 전 확인 사항(현재 응답 상태·이력)

### 3.6 접수 취소 (A3)
- [ ] 미완료 상태에서 취소 가능 · 통계 반영 주의

### 3.7 만족도 조사 (A3)
- [ ] 발송/미발송·제출/미참여 상태 읽기
- [ ] 별점·후기·고객 신고 지불 금액 확인(정산 집계 원천)

- [ ] 운영 중 테이블: 업체명/아이디/전화/주소/상태 + 정렬
- [ ] 활성/비활성 토글 + 확인창 (배정 후보 포함/제외 영향)

## §5 업체 상세 (A4·A5·A7)

### 5.1 서류 심사 (A4)
- [ ] 사업자등록증 원본 크게 보기
- [ ] ★전기공사업 등록증 확인 (없으면 "필수 첨부 도입 전 가입 업체" 안내 표시)
- [ ] 승인 전 대조 항목: 업체명·사업자번호·연락처·주소/서비스 지역·좌표
- [ ] 좌표 없음 안내: 거리순 정렬은 안 되지만 서비스 지역 기준 자동배정은 동작 — 정확한 거리 배정 원하면 좌표 입력

### 5.2 승인/거절 (A4)
- [ ] 가입 승인 → 상태 승인됨
- [ ] 거절 → 사유 입력(신청자가 로그인 시 확인) → 거절 확정

### 5.3 소개자 (A4)
- [ ] 소개자 지정/변경/해제 — 가입 후에도 관리자는 지정 가능
- [ ] "소급 지정 시 과거 조사는 적립되지 않습니다" 규칙 안내

### 5.4 정보 수정 (A5)
- [ ] 계정(아이디 조회만·비밀번호는 변경 시만)·업체 정보·전화·주소·좌표 변환·위도/경도 직접 입력·메모 → 수정 저장

### 5.5 알 관리 ★ (A7)
- [ ] 현재 잔액·변동 이력(최근 50건: 충전/수락 차감/정정) 읽기
- [ ] 충전: **최소 3알 · 1알 = ₩1,000 · 결제 금액 자동 계산 표시** + 사유 필수(예: 무통장 입금 확인) → 처리
- [ ] 정정: delta(양수=증액·음수=감액, **잔액 미만 감액 불가**) + 사유 필수 → 처리
- [ ] 수락 차감 내역과 "0알이면 무차감 수락" 사양 설명
- [ ] 알이 배정 노출 순위·추천 순위에 미치는 영향 설명(순환 현황 "알 보유" 열과 연결)

- [ ] 활성/비활성 토글 + 확인창
- [ ] + 직접 등록 진입

## §8 기사 상세 (A6·A5·A7)

### 8.1 승인/거절 — **촬영 제외**
- 화면에는 `가입 승인` / `거절` 버튼이 남아 있으나 **승인 대기 상태의 기사가 만들어지는 경로가 없다.** 셀프 가입도 관리자 직접 등록도 모두 즉시 승인되고, 거절 API는 승인 대기 건만 받는다. 도달할 수 없는 경로이므로 A4·A6 어느 편에서도 시연하지 않는다.
- 기사에게 실제로 필요한 관문은 승인이 아니라 **근로확인서 서명**(§9)이다. 서명 전에는 배정 후보에 들어가지 않는다 — 이 점을 A6에서 강조한다.

### 8.2 기본 정보 (A6)
- [ ] 근로 형태(일일/상시)·성명·전화·주소·좌표·소개자·평점/후기

### 8.3 근로확인서 열기 (A6) → §9
### 8.4 정보 수정 (A5)
- [ ] 비밀번호 재설정(변경 시만 입력)·정보 수정 저장

### 8.5 알 관리 ★ (A7) — §5.5와 동일 UI(기사 대상)

## §9 근로확인서 — 관리자 (A6)

- [ ] 기사 서명 이미지·서명 시각 확인
- [ ] 계약기간(기간의 정함이 없음)·근무장소·업무 내용·근무일·소정근로시간·주휴일
- [ ] 임금 형태 월급/일급/시급 선택·금액·상여금·기타 항목(예: 식대)
- [ ] 4대보험 체크: 고용·산재·국민연금·건강
- [ ] 임금지급일·지급방법(예금통장/직접)
- [ ] 사업주 정보 자동 기입 확인(설정 연동)
- [ ] 저장 → "저장했습니다"
- [ ] **서명 완료 후에는 전 항목 읽기 전용 전환** — 조회·인쇄만 가능함 안내
- [ ] 인쇄 화면(print) → 브라우저 인쇄/PDF 저장

## §10 기사 직접 등록 (A5)

- [ ] 추천인(선택)·아이디·비밀번호·근로 형태·성명·전화·주소·좌표·메모 → 등록
- [ ] 등록 직후 근로확인 "미작성" 상태로 시작함 안내

## §11 정산 — 소개 수수료 (A8)

- [ ] 행 클릭 → 건별 상세 펼침(소개대상·유형·결제금액·수수료·상태·적립일·별점)

- [ ] CSV 내려받기
- [ ] 선택 지급(체크박스) / 전액 지급 완료 + 확인창 — 실제 이체 확인 후 처리 주의
- [ ] 처리 후 미지급 합계/지급 누계 갱신 확인

## §12 정산 집계 리포트 (A8)

## §13 분석 4종 (A9)

### 13.1 현황
- [ ] 일/주/월 전환
- [ ] 운영 상태·확인 요망·긴급도 분포·접수/완료 추이
- [ ] 배정 퍼널: 최초 제안 시간·수락률·최종 수락 시간·성공률
- [ ] 돈 흐름: 설문 결제 합계/평균·수수료 대기/지급
- [ ] 각 지표 산식 안내(?)

### 13.2 지도
- [ ] 갭 경보(수요>0·공급0 지역) 읽기
- [ ] 공급/수요/압력 정의·위치 미상·출동 현황(고객 목적지 기준)·갱신 시각

### 13.3 설문
- [ ] 응답률·미제출 목록(접수번호·경과일)·발송/미발송 구분·결제 통계
- [ ] 개인정보 취급 주의

### 13.4 평점
- [ ] 이름 검색·정렬(이름/유형/평균 별점/응답 수/완료 건수)
- [ ] 행 클릭 → 개별 후기·완료 실적 상세
- [ ] 표본 적은 고평점 해석 주의

## §14 순환 현황 (A9)

- [ ] 시/도 → 시/군/구 선택
- [ ] 순위표 열: 순위·이름·종류·**★알 보유**·30일 배정(전체)·평균 별점·후기 수 + 총 후보·평균 별점 요약
- [ ] 동률 시 거리 결정·초긴급은 거리 우선(이 순번 미적용)·편집 불가(확인용)

## §15 설정 (A10)

- [ ] 자동배정 토글 + 확인창(즉시 적용)
- [ ] 긴급도별 대기시간(분): 초긴급/긴급/일반
- [ ] 근로확인서 사업주 정보: 사업체명·대표자·주소·전화·사업자등록번호
- [ ] 기본 임금: 일용 일급·상시 월급·임금지급일·지급방법
- [ ] 회사 서명/직인 이미지
- [ ] 저장 → 저장 확인·새로고침 후 유지 확인
- [ ] 대기시간이 실제 배정에 즉시 영향 주의
