# 구판 보관 — 관리자 페이지 운영 매뉴얼 v1.0 (2026-07-31)

**이 폴더의 문서는 더 이상 유효하지 않습니다.** 현행 매뉴얼은
`artifacts/manuals/전기아저씨-관리자-매뉴얼.pdf` (v2.1, 2026-09-07)입니다.

## 왜 보관으로 옮겼나

v1.0은 2026년 7월 화면 기준이라 이후 추가된 기능이 통째로 빠져 있습니다.

- 알 크레딧 관리(충전·정정·수락 차감·노출 순위)
- 접수 상세의 사진 갤러리와 음성 접수 재생
- 배정 추천 순위의 근거 사슬·순위 사유 배지·자동배정 카운트다운
- 전기공사업 등록증 심사
- 접수 즉시 배정과 무응답 10분 순차 재배정

게다가 기사 가입 심사처럼 지금은 존재하지 않는 절차를 안내합니다.
두 문서가 같은 위치에 나란히 있으면 어느 쪽이 현행인지 알기 어려워 분리했습니다.

## 여기에 없는 것 — 스크린샷은 옮기지 않았습니다

`docs/admin-manual/screenshots/` 와 `capture-meta.json`·`annotated-meta.json` 은
**현행 관리자 매뉴얼 v2.1과 관리자 따라하기가 지금도 참조하는 공용 자산**이라 원래 자리에 둡니다.
`artifacts/manuals/관리자-매뉴얼.html` 등이 `../../../docs/admin-manual/screenshots/annotated/` 로
33곳을 가리키므로, 이 폴더로 옮기면 PDF가 빈 이미지로 렌더링됩니다.

## 남겨 둔 이유

7월 시점의 문서 본문은 화면이 어떻게 바뀌어 왔는지 확인할 때 쓸 수 있습니다.
새 문서를 만들 때 참고 자료로만 쓰고, 운영 안내로는 배포하지 마세요.

현행 문서 목록과 감사 결과는 `docs/manual-audit/매뉴얼-전수-체크리스트.md` 를 보세요.
