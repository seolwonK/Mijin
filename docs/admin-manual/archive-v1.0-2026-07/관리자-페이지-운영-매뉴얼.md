# 미진전기 관리자 페이지 운영 매뉴얼

- 작성일: 2026-07-30
- 기준 화면: Cloudtype 라이브 배포 관리자 페이지
- 화면 해상도: 데스크톱 1440px
- 범위: 로그인, 대시보드, 접수 상세, 업체 관리, 전기기사 관리, 순환 현황, 정산, 정산 집계, 분석 4개 탭, 설정

> **개인정보 주의**: 이 문서의 화면은 실제 운영 화면을 기준으로 촬영되어 고객명·전화번호·주소 등 운영 데이터가 보일 수 있습니다. 관리자 내부에서만 사용하고 외부에 전달하지 마십시오.
>
> **표시 방법**: 스크린샷의 **빨간 박스와 숫자**가 클릭하거나 입력할 위치입니다. 번호는 각 화면 아래의 설명과 일치합니다.

---

## 1. 관리자 로그인

![관리자 로그인](screenshots/annotated/00-login.png)

1. **아이디** 입력란을 클릭하고 발급받은 관리자 아이디를 입력합니다.
2. **비밀번호** 입력란을 클릭하고 관리자 비밀번호를 입력합니다.
3. **로그인**을 클릭합니다. 정상 로그인되면 대시보드로 이동합니다.

### 로그인 오류 대응

- `아이디 또는 비밀번호가 올바르지 않습니다`: 입력값과 영문 대소문자를 다시 확인합니다.
- `로그인이 필요합니다`: 세션이 만료된 상태이므로 다시 로그인합니다.
- 공용 PC에서는 업무 종료 후 오른쪽 위 **로그아웃**을 반드시 클릭합니다.
- 비밀번호는 메신저·문서·브라우저 메모에 저장하지 않습니다.

## 2. 공통 상단 메뉴

로그인 후 모든 데스크톱 관리자 화면 상단에 다음 메뉴가 표시됩니다.

| 메뉴 | 용도 |
|---|---|
| 대시보드 | 접수 현황 확인, 상태별 필터, 접수 상세 진입 |
| 업체 관리 | 업체 승인·거절·수정·활성 상태 관리 |
| 전기기사 관리 | 전기기사 승인·수정·활성 상태·근로확인 관리 |
| 순환 현황 | 지역별 자동배정 후보 순서 확인 |
| 정산 | 소개 수수료 적립·지급 처리 |
| 정산 집계 | 월별 고객 신고 수금액 집계와 CSV 출력 |
| 분석 | 현황·지도·설문·평점 분석 화면 열기 |
| 설정 | 자동배정 시간, 사업주 정보, 근로확인서 기본값 관리 |
| 로그아웃 | 관리자 세션 종료 |

**분석** 메뉴는 클릭하면 `현황`, `지도`, `설문`, `평점` 하위 메뉴가 열립니다.

## 3. 대시보드

![대시보드](screenshots/annotated/01-dashboard.png)

1. 상단 **대시보드** 탭입니다.
2. **전체**: 오늘 접수 전체를 표시합니다.
3. **배정대기**: 아직 업체나 전기기사가 배정되지 않은 접수만 표시합니다.
4. **배정됨**: 배정 제안 후 응답을 기다리는 접수를 표시합니다.
5. **진행중**: 수락 또는 출동 중인 접수를 표시합니다.
6. **완료/취소**: 완료되거나 취소된 접수를 표시합니다.
7. **접수 검색**: 접수번호, 고객명, 전화번호, 주소, 고장 내용으로 목록을 좁힙니다.
8. **시각** 열 제목: 클릭하면 접수 시각 기준 정렬 방향이 바뀝니다.

### 대시보드 요약 카드

- **오늘 접수**: 오늘 생성된 전체 접수 수입니다.
- **배정 대기**: 관리자가 수동 배정해야 할 수 있는 접수 수입니다.
- **진행중**: 현재 수락·출동 단계의 접수 수입니다.
- **완료·취소**: 종료 상태 접수 수입니다.
- **긴급 미완료**: 긴급도가 높고 아직 종료되지 않은 접수입니다. 우선 확인합니다.
- **분석 보기**: 분석 현황 화면으로 바로 이동합니다.

### 접수 목록 사용법

1. 업무 목적에 맞는 상태 탭을 누릅니다.
2. 필요한 경우 검색창에 접수번호 또는 고객 정보를 입력합니다.
3. 목록에서 해당 **접수 행**을 클릭하여 상세 화면으로 이동합니다.
4. 빨간색 `관리자 확인 필요` 또는 긴급 표시는 우선 처리합니다.

## 4. 접수 상세

![접수 상세](screenshots/annotated/12-request-detail.png)

1. 상단 **대시보드** 메뉴로 돌아갈 수 있습니다.
2. **뒤로가기**를 누르면 직전 목록으로 돌아갑니다.
3. 고객 전화번호를 누르면 전화 연결이 가능한 기기에서 전화 앱이 열립니다.

### 화면에서 확인할 항목

- 접수번호, 긴급도, 현재 상태
- 고장 내용과 음성 녹음/자동 변환 텍스트
- 고객명, 전화번호, 주소, 접수 시각
- 좌표가 있으면 **지도에서 보기**
- 현재 배정 대상과 배정 이력
- 만족도 조사 제출 여부, 별점, 후기, 고객 신고 지불 금액

### 수동 배정 절차

1. 상태가 **배정대기**인지 확인합니다.
2. 후보 목록에서 업체/전기기사의 거리, 순환 순위, 활성 여부를 확인합니다.
3. 배정할 후보의 **배정**을 클릭합니다.
4. 확인창의 대상이 맞는지 확인한 뒤 확정합니다.
5. 상태가 **배정됨**으로 바뀌었는지 확인합니다.

### 배정 회수

- 업체 응답 대기 중일 때만 **배정 회수**가 나타납니다.
- 회수하면 접수는 배정대기로 돌아가며 안내 문자가 발송될 수 있습니다.
- 중복 배정 방지를 위해 현재 배정 이력을 확인한 후 회수합니다.

### 접수 취소

- 미완료 상태에서 **접수 취소**를 사용할 수 있습니다.
- 취소는 운영 이력과 통계에 반영되므로 고객 요청 또는 명확한 오접수일 때만 실행합니다.

## 5. 업체 관리

![업체 관리](screenshots/annotated/02-providers.png)

1. 상단 **업체 관리** 탭입니다. 숫자 배지가 있으면 승인 대기 업체 수입니다.
2. **+ 직접 등록**: 관리자가 업체 계정을 직접 만듭니다.
3. **승인 대기 카드**: 클릭하면 신청 정보와 사업자등록증 검토 화면으로 이동합니다.
4. **업체명** 열: 클릭하여 오름차순/내림차순 정렬합니다.
5. **전화** 열: 전화번호 기준 정렬합니다.
6. 업체명을 클릭하면 업체 상세 화면으로 이동합니다.
7. **활성** 버튼: 누르면 비활성 전환 확인창이 열립니다.
8. 다른 업체 행도 같은 방식으로 상세 화면에 진입합니다.

### 상태 의미

- **승인 대기**: 사업자 정보 검토 전입니다.
- **승인됨/운영 중**: 로그인과 배정 대상 포함이 가능한 상태입니다.
- **거절됨**: 가입 심사에서 거절된 상태입니다.
- **활성**: 배정 후보에 포함됩니다.
- **비활성**: 계정은 유지되지만 배정 후보에서는 제외됩니다.

> **주의**: 활성 버튼은 단순 표시가 아니라 운영 상태를 즉시 변경합니다. 실수로 누른 경우 확인창에서 취소하십시오.

### 5.1 업체 승인·상세·수정

![업체 상세](screenshots/annotated/13-provider-detail.png)

1. **업체 관리**로 돌아갑니다.
2. 이동 경로의 **업체 관리** 링크입니다.
3. 현재 업체명과 상세 화면 위치를 표시합니다.
4. **뒤로가기**입니다.
5. **원본 크게 보기**: 첨부한 사업자등록증 원본을 새 창에서 확인합니다.
6. **가입 승인**: 사업자등록번호, 등록증, 업체명, 전화번호를 대조한 뒤 승인합니다.
7. **거절**: 거절 사유 입력 화면을 엽니다. 사유를 구체적으로 입력하고 `거절 확정`을 누릅니다.
8. **지정/변경**: 소개자를 지정하거나 변경합니다.

#### 승인 전 필수 확인

- 사업자등록증의 업체명과 신청 업체명이 일치하는지
- 사업자등록번호가 식별 가능한지
- 연락처가 정상 형식인지
- 주소와 서비스 지역이 실제 영업 범위와 맞는지
- 좌표가 없으면 거리순 배정이 제한될 수 있으므로 주소 입력 후 **좌표 변환**을 수행했는지

#### 수정 저장

상세 화면 아래의 계정·업체 정보·위치·메모를 수정하고 **수정 저장**을 누릅니다. 로그인 아이디는 수정할 수 없고, 비밀번호는 변경할 때만 새 값을 입력합니다.

### 5.2 업체 직접 등록

![업체 직접 등록](screenshots/annotated/14-provider-new.png)

1. 뒤로가기로 업체 목록으로 돌아갑니다.
2. **추천인 전화번호**: 소개자가 있는 경우 입력합니다.
3. **확인**: 추천인 조회 결과를 확인합니다.
4. **로그인 아이디**: 중복되지 않는 아이디를 입력합니다.
5. **비밀번호**: 8자 이상으로 입력합니다.
6. **업체명**을 입력합니다.
7. **전화번호**를 입력합니다.
8. 이후 주소, 좌표, 메모를 입력하고 화면 아래 **업체 등록**을 누릅니다.

#### 주소와 좌표

1. 주소를 도로명 또는 지번 형식으로 입력합니다.
2. **좌표 변환**을 클릭합니다.
3. 위도·경도가 채워졌는지 확인합니다.
4. 변환 실패 시 주소를 정정하거나 정확한 위도·경도를 직접 입력합니다.

## 6. 전기기사 관리

![전기기사 관리](screenshots/annotated/03-technicians.png)

1. 상단 **전기기사 관리** 탭입니다.
2. **+ 직접 등록**: 관리자가 전기기사 계정을 만듭니다.
3. **이름** 열: 이름 기준 정렬입니다.
4. **전화** 열: 전화번호 기준 정렬입니다.
5. 전기기사 이름을 클릭하면 상세 화면으로 이동합니다.
6. **활성** 버튼은 해당 전기기사를 배정 후보에서 제외하거나 다시 포함할 때 사용합니다.
7. 다른 전기기사도 이름을 클릭해 상세를 확인합니다.
8. 각 행 오른쪽에서 현재 활성 상태를 확인합니다.

### 근로확인 상태

- **미작성**: 전기기사가 근로확인서를 시작하지 않았습니다.
- **서명 전**: 작성 중이거나 서명이 아직 없습니다.
- **관리자 확인 필요**: 전기기사 서명 제출 후 관리자가 확인해야 합니다.
- **서명 완료(배정 가능)**: 관리자 확인까지 완료되어 배정 가능한 상태입니다.

### 6.1 전기기사 상세

![전기기사 상세](screenshots/annotated/15-technician-detail.png)

1. **전기기사 관리** 메뉴입니다.
2. 이동 경로의 **전기기사 관리** 링크입니다.
3. 현재 전기기사 이름입니다.
4. **뒤로가기**입니다.
5. **근로확인서 열기**: 작성·서명·관리자 확인 상태를 확인합니다.
6. **소개자 지정/변경** 기능입니다.
7. 로그인 아이디는 조회만 가능하며 변경할 수 없습니다.
8. 비밀번호를 바꿀 때만 새 비밀번호를 입력합니다.

#### 상세 화면에서 관리하는 정보

- 승인 상태와 신청 시각
- 근로 형태: 일일 근로자 또는 상시 근로자
- 성명, 전화번호, 주소, 좌표
- 소개자 지정/해제
- 평균 평점과 후기
- 계정 비밀번호 변경
- 활성/비활성 상태

### 6.2 근로확인서

![근로확인서](screenshots/annotated/16-work-confirmation.png)

1. **전기기사 관리** 메뉴입니다.
2. 전기기사 목록으로 이동합니다.
3. 해당 전기기사 상세로 이동합니다.
4. 현재 **근로확인서** 화면입니다.
5. 뒤로가기로 전기기사 상세로 돌아갑니다.
6. **월급** 임금 형태를 선택합니다.
7. **일급** 임금 형태를 선택합니다.
8. **시급** 임금 형태를 선택합니다.

#### 처리 순서

1. 전기기사가 입력한 근로개시일, 근로 형태, 임금 정보를 확인합니다.
2. 전기기사 서명 이미지와 서명 시각을 확인합니다.
3. 임금 형태와 금액, 임금지급일, 지급방법을 확인·보정합니다.
4. 고용보험·산재보험·국민연금·건강보험 적용 여부를 확인합니다.
5. 사업체명, 대표자, 주소, 전화, 사업자등록번호가 맞는지 확인합니다.
6. 내용이 모두 맞으면 관리자 확인/확정 버튼을 누릅니다.
7. **인쇄** 화면에서 출력 형태를 확인하고 브라우저 인쇄 기능으로 PDF 저장 또는 인쇄합니다.

> **주의**: 관리자 확인 완료는 전기기사 배정 가능 여부와 연결될 수 있습니다. 서명과 필수 항목을 확인하지 않고 확정하지 마십시오.

### 6.3 전기기사 직접 등록

![전기기사 직접 등록](screenshots/annotated/17-technician-new.png)

1. 뒤로가기로 전기기사 목록으로 돌아갑니다.
2. **추천인 전화번호**를 입력합니다. 소개자가 없으면 비워 둡니다.
3. **확인**으로 추천인을 조회합니다.
4. **로그인 아이디**를 입력합니다.
5. **비밀번호**를 8자 이상 입력합니다.
6. **일일 근로자** 또는
7. **상시 근로자**를 선택합니다.
8. 성명, 전화번호, 주소, 좌표, 메모를 입력한 뒤 화면 아래 **전기기사 등록**을 누릅니다.

## 7. 순환 현황

![순환 현황 기본](screenshots/annotated/04-rotation.png)

1. 상단 **순환 현황** 탭입니다.
2. **시/도 선택**에서 광역 지역을 선택합니다.
3. **시/군/구 선택**에서 세부 지역을 선택합니다.

![순환 현황 조회 결과](screenshots/annotated/18-rotation-selected.png)

### 조회 절차

1. 시/도를 선택합니다.
2. 시/군/구를 선택합니다.
3. `URGENT·NORMAL 공통 사슬`의 후보 순위를 확인합니다.
4. 총 후보 수, 30일 배정 합계, 평균 별점을 확인합니다.
5. 순위표에서 업체/전기기사 종류, 30일 배정 건수, 평점, 후기 수를 비교합니다.

### 해석 주의사항

- 표의 순위는 일반·긴급 접수의 예상 자동배정 순서입니다.
- 동률일 때는 실제 거리로 최종 순서가 달라질 수 있습니다.
- **초긴급(CRITICAL)**은 거리 우선이므로 이 순번을 그대로 사용하지 않습니다.
- 이 화면은 확인용이며 순서를 직접 편집하는 화면이 아닙니다.

## 8. 정산 — 소개 수수료

![정산 목록](screenshots/annotated/05-commissions.png)

1. 상단 **정산** 탭입니다.
2. **소개자** 열 정렬입니다.
3. **미지급 합계** 열 정렬입니다.
4. **지급 누계** 열 정렬입니다.
5. 소개자 행을 클릭하면 해당 소개자의 건별 수수료 상세가 펼쳐집니다.

![정산 상세](screenshots/annotated/19-commission-detail.png)

1. 현재 정산 메뉴입니다.
2. 소개자 정렬입니다.
3. 미지급 합계 정렬입니다.
4. 지급 누계 정렬입니다.
5. **적립 월 필터**로 특정 월의 적립 내역만 조회합니다.
6. **CSV**를 눌러 현재 소개자·월 조건의 내역을 내려받습니다.
7. 건별 체크박스를 선택한 뒤 **선택 지급**으로 선택 건만 지급 완료 처리합니다.
8. **전액 지급 완료**는 현재 소개자의 미지급 전액을 한 번에 처리합니다.

### 지급 처리 절차

1. 소개자 행을 눌러 상세를 엽니다.
2. 월 필터가 올바른지 확인합니다.
3. 소개대상, 유형, 결제금액, 수수료, 상태, 적립일, 별점을 검토합니다.
4. 실제 지급 자료와 대조합니다.
5. 일부 지급이면 체크박스 선택 후 **선택 지급**, 전액 지급이면 **전액 지급 완료**를 누릅니다.
6. 확인창의 소개자명과 금액을 다시 확인하고 확정합니다.
7. 미지급 합계와 지급 누계가 갱신됐는지 확인합니다.

> **주의**: 지급 완료 처리는 회계 상태를 변경합니다. 실제 이체 확인 전에는 누르지 마십시오.

## 10. 분석 메뉴

상단 **분석**을 클릭한 뒤 하위 메뉴 `현황`, `지도`, `설문`, `평점` 중 하나를 선택합니다.

### 10.1 분석 현황

![분석 현황](screenshots/annotated/07-analytics-dashboard.png)

1. **분석** 메뉴입니다. 클릭하면 하위 메뉴가 열립니다.
2. **일** 단위로 지표를 집계합니다.
3. **주** 단위로 지표를 집계합니다.
4. **월** 단위로 지표를 집계합니다.
5~8. 각 **? 산식 안내**를 눌러 해당 지표의 계산 기준과 분모·분자를 확인합니다.

#### 주요 지표

- 운영 상태: 완료, 취소, 접수, 배정 건수
- 확인 요망: 관리자 개입이 필요한 접수
- 긴급도 분포: 미완료 접수의 초긴급·긴급·일반 분포
- 접수·완료 추이: 기간별 유입과 종료 추세
- 최초 제안까지 시간: 첫 배정 제안 속도
- 응답완료 제안 수락률: 응답된 제안 중 수락 비율
- 최종 수락까지 시간: 고객 관점의 실제 배정 완료 시간
- 접수 단위 성공률: 전체 접수 중 성공적으로 수락된 비율
- 돈 흐름: 설문 결제 합계·평균, 수수료 대기·지급 금액

### 10.2 전국 지도 현황

![전국 지도 분석](screenshots/annotated/08-analytics-map.png)

1. **분석** 메뉴입니다.
2. **? 산식 안내**에서 수급 압력 계산법을 확인합니다.
3~8. 지역명을 클릭하면 해당 지역 상세 또는 드릴다운 정보가 표시됩니다.

#### 화면 해석

- **갭 경보**: 수요는 있지만 활성 공급자가 없는 지역을 우선 표시합니다.
- **공급**: 배정 가능한 활성 업체·전기기사 수입니다.
- **수요**: 해당 지역 미완료 접수 수입니다.
- **압력**: 수요 ÷ 공급입니다. 값이 높을수록 공급 부족 가능성이 큽니다.
- **위치 미상**: 주소·좌표를 지역으로 판별하지 못한 접수입니다.
- **출동 현황**: 차량 GPS가 아니라 고객 목적지 기준입니다.
- 마지막 갱신 시각을 확인하여 데이터 신선도를 판단합니다.

### 10.3 설문 현황

![설문 분석](screenshots/annotated/09-analytics-surveys.png)

1. **분석** 메뉴입니다.
2. 응답률 옆 **? 산식 안내**에서 발송 대비 제출 비율을 확인합니다.
3. 결제 통계 옆 **? 산식 안내**에서 합계·건수·평균 산식을 확인합니다.

#### 운영 방법

- 응답률이 낮으면 미제출 목록의 접수번호·고객명·전화·경과일을 확인합니다.
- 설문 미발송과 미제출을 구분합니다.
- 결제 통계는 고객이 설문에 입력한 금액 기준입니다.
- 개인정보가 포함되므로 미제출 목록을 외부 파일로 복사하지 않습니다.

### 10.4 평점 현황

![평점 분석](screenshots/annotated/10-analytics-ratings.png)

1. **분석** 메뉴입니다.
2. **? 산식 안내**에서 순위 산정 기준을 확인합니다.
3. **이름 검색**으로 업체나 전기기사를 찾습니다.
4. **이름** 기준 정렬입니다.
5. **유형** 기준 정렬입니다.
6. **평균 별점** 기준 정렬입니다.
7. **응답 수** 기준 정렬입니다.
8. **완료 건수** 기준 정렬입니다.

![평점 상세](screenshots/annotated/20-rating-detail.png)

#### 상세 확인 절차

1. 순위표에서 업체 또는 전기기사 행을 클릭합니다.
2. 아래 **평점 상세** 영역에서 기간별/개별 후기와 완료 실적을 확인합니다.
3. 평균 별점만 보지 말고 응답 수와 완료 건수를 함께 확인합니다.
4. 응답 수가 적은 높은 평점은 표본이 부족할 수 있습니다.
5. 민원 대응 시 원문 후기를 운영 목적 범위에서만 사용합니다.

## 11. 설정

![관리자 설정](screenshots/annotated/11-settings.png)

1. 상단 메뉴에서 **설정**을 선택합니다. 화면의 분석 메뉴 빨간 표시는 공통 상단 메뉴 위치 참고용입니다.
2. **뒤로가기**로 이전 화면으로 이동합니다.
3. **자동배정 토글**: 자동배정을 켜거나 끕니다. 변경 확인창이 표시됩니다.
4. **초긴급 대기시간**을 분 단위로 입력합니다.
5. **긴급 대기시간**을 분 단위로 입력합니다.
6. **일반 대기시간**을 분 단위로 입력합니다.
7. 근로확인서에 들어갈 **사업체명**을 입력합니다.
8. **대표자**를 입력합니다.

### 나머지 설정 항목

- 사업주 주소, 전화, 사업자등록번호
- 일용 기본 일급
- 상시 기본 월급
- 임금지급일
- 지급방법: 예금통장 입금 또는 직접 지급
- 회사 서명/직인 이미지
- 화면 맨 아래 **저장** 버튼

### 안전한 설정 변경 절차

1. 현재 값을 별도로 기록합니다.
2. 변경 이유와 적용 시각을 확인합니다.
3. 한 번에 필요한 항목만 수정합니다.
4. 자동배정 토글은 확인창의 변경 방향을 다시 읽고 확정합니다.
5. 화면 아래 **저장**을 누릅니다.
6. 저장 완료 메시지를 확인합니다.
7. 새로고침 후 값이 유지되는지 확인합니다.

> **주의**: 자동배정 대기시간은 실제 배정 시점에 즉시 영향을 줍니다. 근로확인서 사업주 정보와 기본 임금은 이후 생성되는 문서에 자동 기입되므로 정확한 사업자 정보만 입력하십시오.

## 12. 일일 운영 권장 순서

### 업무 시작

1. 로그인 후 대시보드의 **긴급 미완료**와 **배정대기**를 확인합니다.
2. 업체 관리와 전기기사 관리의 승인 대기 배지를 확인합니다.
3. 순환 현황에서 주요 서비스 지역의 후보 부족 여부를 확인합니다.
4. 분석 현황의 `확인 요망`을 확인합니다.

### 업무 중

1. 배정대기 접수를 우선순위와 긴급도에 따라 처리합니다.
2. 배정 제안 응답이 지연되면 접수 상세에서 회수 여부를 판단합니다.
3. 신규 업체·전기기사 신청을 서류와 연락처 기준으로 심사합니다.
4. 전기기사 근로확인서의 서명·사업주 정보·임금 정보를 확인합니다.
5. 지급 처리 전 실제 이체 자료와 수수료 내역을 대조합니다.

### 업무 종료

1. 미완료 긴급 접수와 관리자 확인 필요 건을 인계합니다.
2. 정산 처리 건의 합계와 지급 자료를 대조합니다.
3. 설정을 변경했다면 변경 전후 값을 기록합니다.
4. 오른쪽 위 **로그아웃**을 클릭합니다.

## 13. 실수 방지 체크리스트

- [ ] 승인/거절 대상의 이름과 유형을 다시 확인했다.
- [ ] 거절 사유는 신청자가 이해할 수 있게 구체적으로 작성했다.
- [ ] 활성/비활성 전환이 배정 후보에 미치는 영향을 확인했다.
- [ ] 배정 회수 전 현재 업체 응답 상태와 배정 이력을 확인했다.
- [ ] 접수 취소 전 고객 요청 또는 오접수 근거를 확인했다.
- [ ] 지급 완료 전 실제 이체 여부와 금액을 확인했다.
- [ ] 설정 저장 후 새로고침으로 반영 여부를 확인했다.
- [ ] 고객 전화번호·주소·후기 등 개인정보를 외부에 공유하지 않았다.
- [ ] 업무 종료 후 로그아웃했다.

## 14. 문제 해결

| 증상 | 확인 및 조치 |
|---|---|
| 목록이 비어 있음 | 선택한 상태 탭, 검색어, 월 필터를 초기화하고 새로고침합니다. |
| 승인이 되지 않음 | 필수 사업자/전기기사 정보, 승인 상태, 오류 메시지를 확인합니다. |
| 자동배정 후보가 없음 | 대상 지역, 활성 상태, 승인 상태, 좌표/서비스 지역, 근로확인 완료 여부를 확인합니다. |
| 거리순 정렬이 이상함 | 업체·전기기사의 주소를 좌표 변환했는지 확인합니다. |
| 정산 금액이 다름 | 정산 월, 고객 설문 지불금액 입력 여부, 지급 상태를 확인합니다. |
| 분석 수치가 바로 바뀌지 않음 | 화면의 마지막 갱신 시각을 확인하고 잠시 후 새로고침합니다. |
| 저장 버튼이 비활성 | 필수 입력값, 숫자 형식, 비밀번호 최소 길이를 확인합니다. |
| 로그인 상태가 풀림 | 보안을 위한 세션 만료일 수 있으므로 다시 로그인합니다. |
