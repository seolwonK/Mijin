# R2 파일 저장 검증 — 2026-09-10

## 확인된 원인과 수정

- 제공된 R2 키의 인증은 정상. S3 ListBuckets 200, 설정된 `mijin-uploads`의 HeadBucket 404로 버킷 누락 확인.
- `mijin-uploads` 전용 버킷 생성 완료(CreateBucket 200). 공개 도메인/공개 접근 설정 없음.
- 신규 음성·사업자등록증·전기공사업 등록증은 R2에 본문, StoredFile에 ID·MIME·storageKey를 저장하도록 변경.
- 현장 사진은 기존 R2 경로 사용. R2 장애 시 DB 긴급 저장 유지.
- R2 미설정 개발 환경과 기존 DB/파일시스템 파일의 조회 호환 유지. 기존 파일의 일괄 이전은 수행하지 않음.
- DB 메타 저장 또는 접수/가입 실패 시 신규 파일 정리. R2 삭제 실패 시 재시도용 메타 유지.

## 운영 적용 인계

사용자가 CloudType `@nqsolution / migin / main / mijin` 환경변수를 직접 추가하기로 함.
`R2_ACCOUNT_ID`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`는 제공한 값, `R2_BUCKET=mijin-uploads`.
값에 따옴표 없이 입력하고 main 코드 반영 후 **배포하기** 실행. 배포 시 DB 스키마 변경은 자동 적용.
이 보고서의 실제 R2 검사는 로컬에서 수행했으며, 운영 컨테이너의 환경변수 적용 완료를 뜻하지 않음.

Cloudflare 공식 API 참고: [S3 compatibility](https://developers.cloudflare.com/r2/api/s3/api/).
