# 2026-09-10 라이브 화면 매뉴얼 개정

기준: `https://전기아저씨.com`의 2026-09-10 화면과 `96a024a`의 배포 소스. 기존 매뉴얼 4종과 따라하기 4종을 v3.0으로 재작성했습니다.

## 변경 반영

| 변경된 기능 | 반영한 내용 | 매뉴얼 절 |
| --- | --- | --- |
| 관리자 업무 이동 | 메뉴 묶음·메뉴 검색·열린 화면 탭·모바일 메뉴 | 관리자 `a-navigation` |
| 관리자 접수 관리 | 요약 기준·상태 필터·검색/정렬·선택 패널·배정 확인창 | `a-dashboard`, `a-request`, `a-assignment` |
| 업체·기사 정보 | 관리자 편집 범위와 본인의 서비스 지역 편집 경로 구분 | `a-provider`, `a-registration`, `a-tech`, 포털 `*-profile` |
| 소개자 관리 | 지정·변경·해제 즉시 반영, 과거 설문 소급 적립 제외 | `a-referrer` |
| 포털 운영 현황 | 알·누적 수수료·응답/진행·30일 성과·조회 오류·배정 자격 안내 | 포털 `*-home`, `*-notify`, `*-job` |
| 포털 지난 내역 | 주소/고장/고객 검색·배정 상태 선택·20건씩 페이지 이동 | 포털 `*-history` |
| 포털 수수료 | 홈 최근 3건과 전체 50건씩 조회, 적립일·지급 상태 | 포털 `*-commission` |
| 알 충전 화면 | 수량·금액·입금 계좌·계좌 미등록·관리자 입금 확인 후 충전 | 포털 `*-charge`, `a-eggs`, `a-settings` |
| 내 정보 | 업체·기사 연락처/주소/지역·새 배정 받기·저장 적용 | 포털 `*-profile` |
| 기사 가입과 확인서 | 본인인증 후 재입력·10분 유효시간·자동 로그인·직접/이름 서명·서명본 정정 제한 | 기사 `t-verify`, `t-contract` |
| 순환·분석 | 지역/대상 필터, 현재 업무와 기간 지표, 지도 등록 수·실제 후보 구분 | `a-rotation`, `a-analytics`, `a-map` |
| 정산·설문 | 한국 시간 설문 응답월·신고 원본·0원/미입력·설문 재발송 확인 | `a-settlement`, `a-surveys` |
| 고객 접수·조회 | 음성·사진·입력 오류·최신 20건·15초 갱신·문자 대체 조회·설문 선택 항목 | 고객 `c-description`~`c-survey` |
| 배정 예외 | 자동배정 제외 이력, 초긴급 비교, 자동배정 OFF에서도 무응답 회수, 거절 재배정 조건 | 배정 `r-overview`~`r-timeout`, 포털 `*-progress` |

포털 항목의 `*`는 업체 `p`, 기사 `t`입니다. 운영 매뉴얼과 따라하기는 같은 원고를 공유해 설명이 어긋나지 않도록 했습니다.

## 산출물

- HTML 8종과 [목록 페이지](../../artifacts/manuals/index.html).
- 대응하는 PDF 8종, 총 165쪽. 표지·머리말·개정일을 v3.0 / 2026-09-10으로 통일했습니다.
- 라이브 화면 78개 중 본문에 필요한 77개를 연결했습니다. 누락된 기사 포털 13개를 추가 촬영하고, 업체와 고객의 중복·스크롤 누락 화면을 갱신했습니다.
- 서명 완료본과 완료된 배정의 캡처에는 상태를 명시했습니다. 현재 계정에 없는 상태를 만들기 위해 운영 데이터나 화면 응답을 바꾸지 않았습니다.

## 검증

- 빌드에서 본문에 필요한 캡처 **77/77개**의 파일·라이브 도메인·개정 기준·SHA-256을 확인했습니다.
- HTML 8종과 목록 페이지의 이미지, CSS/PDF 링크, 목차 앵커, 초안 표시 유무를 확인했습니다.
- HTML을 390px와 1440px로 열어 가로 넘침이 없는 것을 확인했습니다.
- PDF 전 페이지를 이미지로 렌더링해 배치·주석·페이지 나눔을 검수했습니다. 주의사항만 다음 장으로 넘어가는 배치를 정리했습니다.
- PDF의 개정 머리말, 빈 페이지, 글자 영역 넘침, 구판 날짜·미촬영 안내 잔존을 점검했습니다.
- 문서 생성 스크립트 구문 검사와 `git diff --check`를 통과했습니다.

이번 검증은 문서·캡처·출력에 한정합니다. 실제 수락·출동·완료·서명·입금·문자 수신·본인인증은 다시 실행하지 않았으며, 처리 조건은 배포 소스와 화면에 대조했습니다.
