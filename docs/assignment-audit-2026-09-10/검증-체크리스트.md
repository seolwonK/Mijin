## 검증 방법과 범위

- 매 실행마다 **새로운 로컬 PostgreSQL DB**를 생성하고 운영과 같은 Prisma 마이그레이션을 모두 적용했습니다. DB 이름은 `mijin_assignment_audit_*`이며 실행 종료 후 삭제합니다.
- 정렬 검증은 후보 **1,296개 조합 × 모든 후보 쌍 × 긴급도 3종 = 5,038,848회** 비교합니다. 문서의 우선순위를 독립적인 순위 벡터로 표현해 제품 comparator와 대조하고, 입력 순서를 96회 바꿔 결과와 화면 배지를 확인합니다.
- 집중 통합 테스트는 실제 PostgreSQL 트랜잭션·행 잠금·상태·원장을 확인합니다. 인증과 문자 전송만 대체하며, 특정 경합에서는 조회 직후의 중단점을 넣어 순서를 확정합니다. 저장 실패는 **DB 트리거의 실제 예외**로 주입합니다.
- HTTP 검증은 실제 Next.js 서버·세션 검증·API·DB를 사용합니다. 고객 접수에서 시작하는 즉시 배정, cron 재배정, 업체·기사 수락, 권한 검사까지 확인합니다.
- 화면 검증은 Chromium에서 **390px 모바일 폭과 1440px PC 폭**으로 수행합니다. 배정 API 응답을 가로채지 않고 실제 클릭 결과를 DB와 대조합니다.
- 문자 전송은 `console`, 본인인증은 `mock`, R2는 비활성화했습니다. 배정 문자 요청과 로컬 발송 로그를 검증했으며 통신사의 실제 SMS 도착을 검증한 것은 아닙니다.

| 3. 관리자 알림 중복 | F06: 후보 없는 접수에 즉시배정 10개 동시 호출 시 알림 10회 | DB에서 needsAttention false→true 전환에 성공한 호출만 알림. 결과 1회 |
| 4. 한 건의 오류가 뒤의 처리 중단 | F07/F08: 첫 접수 조회 실패나 회수 저장 실패가 나머지 회수·신규 배정을 막음 | 접수별 오류를 기록하고 다음 건을 계속 처리. 실패한 건은 다음 주기에 재시도 |
| 5. 오래된 후보 자격으로 배정 | F09~F11: 조회 뒤 비활성·승인 철회·계약 변경이 되었어도 과거 결과로 배정 | 배정 트랜잭션에서 자격 재확인, 커밋까지 관련 행 공유 잠금. 자동·수동 모두 새 자격 반영 |

수정 전 증거는 [최초 실패 목록](evidence/before/reproduced-failures.json)과 [추가 실패 목록](evidence/extended-before/reproduced-failures.json)에 있습니다. 최초 14개, 추가 7개의 실패 테스트로 위 결함들을 재현했습니다. 단순한 정상 반환값 외에 저장된 접수 상태, 배정 수·상태, 알 원장, 문자 호출 수를 단언했습니다.

기존 소유권 테스트 2개는 출동 중인 한 접수에 REQUESTED를 하나 더 만드는 비정상 픽스처였습니다. 거절의 정상 소유권 검증은 별도 ASSIGNED 접수로 분리했고, 기존의 비정상 상태는 R08에서 명시적으로 거부되는지 확인합니다. 정산 회귀 테스트의 DB 가드도 이번 전용 로컬 DB를 허용하도록 확장했습니다.

## 현행 정책상 구별할 사항

1. **접수 즉시배정에는 설정 대기시간이 적용되지 않습니다.** 설정 대기시간은 워커가 밀린 접수를 처리하는 기준이며, 담당자 응답 제한 10분과 다릅니다.
2. **자동배정 OFF여도 이미 AUTO로 배정된 건을 거절하면 다음 후보에게 즉시 재배정될 수 있습니다.** 기존 코드는 배정 출처를 기준으로 이 분기를 결정합니다. 이번 작업에서는 이 운영 정책을 바꾸지 않았습니다.
3. 거절 직후 재배정은 **거리 확인 후보만**, 신규 즉시배정·대기 워커·무응답 재배정은 **지역을 담당하면 거리 미확인 후보도** 허용합니다.
4. 수동 배정은 지역 밖·기존 거절/회수 이력도 선택할 수 있지만 활성·승인·기사 계약 요건은 우회하지 않습니다.
5. 알은 배정 요청 시 차감하지 않고 **수락 시 1알** 차감합니다. 잔액 0이어도 수락할 수 있습니다.
6. cron 응답의 `assigned`는 대기 접수 배정 수입니다. 무응답 회수 중 즉시 재배정 수까지 포함하는 전체 배정 지표는 아닙니다.

## 실행 증거와 재현

```sh
npm run test:assignment
```
