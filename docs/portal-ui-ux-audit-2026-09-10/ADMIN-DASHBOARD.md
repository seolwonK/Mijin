# 관리자 메인 대시보드 개선

> 이전 디자인 반복의 기록이다. 현재 적용된 차콜·아이보리·노랑 디자인과 검증 결과는 [최종 구현 기록](COMMAND-CENTER.md)을 참고한다.

검증 환경: 격리된 로컬 DB와 `http://localhost:3001/admin`. 실제 배정이나 문자 발송 없이 조회와 화면 조작을 확인했다. 배정 성공·충돌·중복 클릭 검증은 API 응답을 모킹한 Playwright 테스트로 진행했다.

## 적용 내용

| 영역 | 변경 |
| --- | --- |
| 전체 구성 | 여백과 둥근 모서리를 늘리고, 네이비 요약 영역·흰색 작업 영역·블루 선택 표시로 대비를 만들었다. 노란 번개와 배정 대기 수치로 전기 서비스의 색감을 더했다. 장식용 그래프는 사용하지 않는다. |
| 요약 | 큰 숫자를 중심으로 정리하고 배정 대기는 노란색, 긴급 미완료는 코랄색으로 강조한다. 조회 범위에 맞춰 `오늘 접수`를 `조회된 접수`로 수정하고 최근 최대 200건이라는 범위를 명시했다. |
| 접수 목록 | 접수 내용·고객·진행 상태·접수 시각의 4열로 묶었다. 접수번호와 긴급도는 내용 위에, 담당자와 설문 상태는 진행 상태 아래에 배치했다. |
| 긴 텍스트 | 내용·주소·이름의 한 줄 말줄임을 제거하고 줄바꿈을 허용했다. 전화번호는 별도 줄의 전화 링크로 제공한다. |
| 목록 조작 | 상태 필터, 접수번호·고객·주소·내용 검색, 하이픈을 포함한 전화번호 검색, 시각 정렬과 25건 단위 페이지 이동을 제공한다. |
| 선택 영역 | 선택 전에는 목록이 전체 너비를 사용한다. 선택 시 `접수 상세` 패널을 열고 닫을 수 있다. 1280px 미만에서는 목록 위에 배치해 폭이 좁아지는 것을 방지한다. |
| 상세 정보 | 네이비 헤더와 노란 접수번호로 선택 영역을 구분한다. 고객과 현장 → 전체 접수 내용 → 배정 후보/현황 → 설문 → 배정 이력 순으로 정리했다. 전체 상세 페이지로 이동하는 링크를 유지한다. |
| 배정 후보 | 이름·알·거리·평점을 우선 표시하고 첫 후보에 얇은 블루 테두리를 둔다. 주소·연락처·최근 배정 횟수·순위 근거는 펼쳐서 확인한다. 패널에서는 3명부터 표시하고 나머지를 펼칠 수 있다. |
| 상태 표시 | 상태는 작은 점과 텍스트로 표시하고, 긴급도에만 작은 배경색을 사용한다. 선택 탭·선택 행·배정 버튼에는 같은 블루를 사용한다. |
| 배정 버튼 | 좁은 패널에서도 글자가 세로로 잘리지 않도록 너비와 줄바꿈을 제어했다. 기존 배정 순서와 서버 요청 형식은 유지한다. |
| 오류 처리 | 접수/후보 조회 실패와 로딩·빈 상태를 구분하고 재시도를 제공한다. 최신 정보를 가져오지 못하면 배정을 막는다. |
| 확인창 | 네이티브 모달로 배경 조작을 차단하고, 취소에 초기 초점을 둔다. Tab/Shift+Tab 순환, Escape 취소, 닫은 뒤 원래 버튼으로 초점 복귀를 지원한다. |

## 검증 체크리스트

- [x] 4열 목록, 긴 내용 전체 표시, 전화 링크
- [x] 선택 전 후보 API 미호출, 선택한 접수의 후보만 조회
- [x] 빠르게 다른 접수를 선택할 때 이전 후보가 섞이지 않음
- [x] 상태 필터·주소/전화번호 검색·빈 결과·시각 정렬
- [x] 25건 페이지 이동과 필터 변경 시 첫 페이지로 복귀
- [x] 후보 펼치기/접기, 자동배정이 꺼진 경우 예정 문구 숨김
- [x] 접수/후보 API 실패 구분 및 재시도
- [x] 배정 요청의 기존 `assigneeKind`/`assigneeId` 유지
- [x] 취소 시 배정 미전송, 빠른 확인 두 번에도 한 번만 전송
- [x] 409 충돌 메시지와 배정 성공 후 목록 새로고침
- [x] 확인창 양방향 Tab 순환, Escape 취소, 원래 배정 버튼으로 초점 복귀
- [x] 요약 API 8초 폴링, 요약 카드의 필터·분석 링크
- [x] 모바일·태블릿·데스크톱 7개 너비에서 가로 넘침 없음
- [x] 320/390/768/1000/1280/1440/1920px에서 본문 axe WCAG A/AA 자동 검사 위반 없음
- [x] 실제 로컬 데이터로 목록·선택 패널·배정 확인/취소 확인, 브라우저 JS 오류 없음
- [x] 프로덕션 빌드 및 TypeScript 검사 통과
- [x] 변경 소스 ESLint 통과, 관련 Playwright 테스트 17개 통과

테스트: `tests/admin-dashboard-ui.spec.ts`, `tests/admin-queue.spec.ts`, `tests/admin-analytics-strip.spec.ts`의 메인 대시보드 관련 항목. 별도 분석 대시보드 항목 2개는 이번 변경 범위에서 제외했다.

기존 목록 API는 최대 200건을 조회한다. 화면의 검색·필터·페이지 이동은 이 조회 결과 안에서 동작한다. 전체 기간 검색을 위한 서버 페이지네이션은 이번 디자인 변경에 포함하지 않았다. 기존 Next.js middleware 전환 및 업로드 경로 추적 경고는 남아 있으나 빌드는 성공했다.
