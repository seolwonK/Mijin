# 포털 대시보드와 배정 목록

2026-09-10. 업체·기사 공통 홈의 정보 순서와 작업 목록을 수정했다.

- 최상단에 알 잔액·배정 노출 순위·소개 수수료 지급 대기/완료·응답 대기/진행 중·최근 30일 배정/수락·후기 요약을 배치했다. 수수료는 전체 기간 합계이며, 알을 금액으로 환산하지 않는다.
- 대기·진행 건수를 누르면 해당 목록으로 이동한다. 수수료 금액은 전체 수수료 내역으로 연결한다. 로딩 중에는 0 대신 대시를 표시하고, 조회 실패·재시도·마지막 데이터 안내를 유지한다.
- 배정별 색상 테두리·파스텔 배지·반복 박스를 없애고 구분선으로 작업을 나눈다. 주소, 고장 내용, 배정 시각 순서로 읽을 수 있다. 긴급도와 응답 시간만 필요한 색으로 강조한다.
- 전화·길찾기·방문 이력·배정/작업 상세 이동, 동일 장소 이력 펼치기를 유지했다. 지난 내역 검색 화면에도 같은 목록을 적용했다.
- PC에서는 작업 목록과 수수료·추천·후기를 두 영역으로 배치한다. 모바일에서는 상단 현황 다음에 작업 목록을 배치한다.
- 홈의 수수료 상세는 최근 3건, 후기는 기본 3건을 표시한다. 전체 내역과 후기 펼치기/접기로 나머지를 확인할 수 있다.

## 검증

- 최종 프로덕션 빌드 성공, TypeScript 및 변경 파일 ESLint 통과.
- 기존 UI 회귀 25개 통과: 상태·로그인/프로필·배정 상세·사진·계약서·이력 검색·9자리 금액·조회 실패 복구 포함. [실행 기록](dashboard-evidence/ui-tests.log)
- 실제 테스트 계정 2개의 폼 로그인, 알 이용 안내, 후기 펼치기/접기, 배정 바로가기 확인.
- 두 역할에서 320·360·390·768·1280·1440px 가로 넘침 없음. 상단 현황이 배정 목록보다 먼저 표시되는 것을 확인.
- 두 홈의 WCAG A/AA 자동 검사 위반 0건, 브라우저 JavaScript 오류 0건. [검증 결과](dashboard-evidence/verification.json)
