# 순환 현황 개선

로컬 주소: `http://localhost:3001/admin/rotation`.

기존 화면은 지역 선택 전까지 데이터를 표시하지 않았고 모바일에서는 데스크톱 이용 안내만 제공했다. 전국 대상 수와 지역별 후보 수를 먼저 표시하고, 후보가 가장 많은 시도와 그 안의 시군구를 최초 조회 지역으로 선택하도록 바꿨다. 이후에는 URL과 같은 브라우저 탭의 마지막 조회 지역을 사용한다.

## 변경 내용

| 영역 | 적용 |
| --- | --- |
| 첫 화면 | 전국 배정 대상·업체·전기기사·알 보유 대상 수를 한 줄 요약으로 제공한다. 데이터가 있는 경우 지역 선택 없이 순위를 바로 조회한다. |
| 지역 탐색 | 데스크톱은 17개 시도별 후보 목록, 모바일은 선택 상자를 사용한다. 시군구별 후보 수도 선택 상자에 표시한다. |
| 우선 후보 | 첫 번째 후보의 이름·알 보유량·최근 30일 배정 횟수·평점과 후기 수를 먼저 보여준다. 노란색은 이 영역과 선택 상태에 집중했다. |
| 전체 순위 | 업체/기사 구분·이름 검색·25건 페이지 이동을 제공한다. 검색과 필터 후에도 API가 반환한 원래 순번을 보존한다. 임의 정렬은 제공하지 않는다. |
| 관리 이동 | 후보 이름과 상세 링크에서 해당 업체/기사의 관리 화면으로 이동한다. 동명이인을 구별할 수 있도록 API에 기존 대상의 id와 안정 키를 추가했다. |
| 모바일 | 조회를 차단하던 안내를 제거하고 지역 선택·후보 정보·검색·필터·페이지 이동을 모두 제공한다. |
| 읽기 | 작은 글자의 크기와 대비를 보완하고, 후기 없는 후보는 실제 평점 3.0 대신 `후기 없음`으로 표시한다. |
| 조회 상태 | 요약·지역 순위의 오류를 구분한다. 조회 실패·빈 후보·검색 결과 없음·로딩을 별도로 표시하고 재시도를 제공한다. 갱신 실패 후 이전 자료를 보여줄 때는 마지막 조회 자료라는 안내를 표시한다. |
| 순위 설명 | 여러 경고 배지 대신 한 문장 안내와 하단 순위 기준을 제공한다. 초긴급의 다른 규칙과 실제 접수의 거리·응답 이력 영향을 명시한다. |

## 집계와 순위의 의미

- 전국 대상은 기존 `getCandidates`의 자격 조건을 재사용한다. 활성·승인된 업체와 활성·승인·계약 확정된 전기기사다. 현재 다른 작업을 하지 않는 인원 수를 뜻하지 않는다.
- 시도별 후보 수는 그 시도 내 어느 시군구라도 담당하는 대상의 합집합이다. 여러 구를 담당하는 동일 대상은 해당 시도에서 한 번만 센다. 전국 수치도 대상 키로 중복을 제외한다.
- 시군구를 선택하면 실제 기존 지역 매칭 조건으로 순위를 조회한다. `시/도 공통 담당`은 시도 전체 또는 전국을 담당하는 후보만 보여주는 기존 동작을 명확히 이름 붙인 것이다.
- 일반·긴급은 담당 지역 후보 안에서 알 많은 순 → 최근 30일 배정 적은 순 → 평점 높은 순으로 비교한다. 최근 30일 수치는 모든 지역에서의 수락·거절 응답 건수다. 후기 없는 후보의 계산용 기본값 3.0을 실제 평점처럼 표시하지 않는다.
- 이 화면은 좌표와 특정 접수의 응답 이력이 없는 참고 순위다. 확정 배정 순서나 초긴급의 순위가 아니다. 실제 초긴급의 같은 시군구 → 알 → 거리 규칙과 배정 로직은 수정하지 않았다.
- 전국 요약은 60초, 선택 지역 순위는 기존과 같이 30초마다 갱신한다. 수동 새로고침은 둘을 함께 조회한다.

API 변경은 기존 관리자 GET `/api/admin/rotation`에 `view=overview` 조회 모드와 지역 결과의 `id`·`key` 필드를 추가한 것이다. 요약 모드는 기존 매칭 대상 조회를 한 번 사용하고 순위 통계 쿼리는 생략한다. 지역마다 별도 DB 조회를 반복하지 않는다. 기존 지역 필수 조건·잘못된 지역 오류·관리자 인증과 지역 순위 응답의 기존 필드를 유지했다. DB 스키마와 배정/문자 처리에는 변경이 없다.

## 검증

- [x] 전국 합계와 시도 합집합의 중복 제거, 전국/시도/특정 구 담당, 세종, 후보 0명
- [x] 최초 추천 지역 선택, URL·마지막 조회 지역 복원
- [x] 기존 API 인증·지역 입력 검증·서버 순서·담당 지역 필터 유지
- [x] 후보 이름·알·평점·후기 없음·관리 링크 표시
- [x] 이름 검색·구분 필터·페이지 이동 후 원래 순번 유지
- [x] 늦은 이전 지역 응답 차단
- [x] 요약 실패 시 수동 지역 선택, 지역 조회 실패·재시도·빈 후보 구분
- [x] 갱신 실패 시 마지막 조회 자료 안내, 자동 폴링 유지
- [x] 모바일 조회·검색·필터·관리 이동, 관리자 공통 메뉴와 업무 탭 회귀 검사
- [x] 실제 데이터에서 17개 시도의 추천 시군구 후보 수와 기존 지역 조회 결과 일치
- [x] 320/390/768/1000/1280/1440/1920px 가로 넘침 없음
- [x] 위 7개 너비의 axe WCAG A/AA 자동 검사 통과, 브라우저 JavaScript 오류 없음
- [x] 실제 관리자 API 변경 요청 없음, 비로그인 요약 조회 401
- [x] 프로덕션 빌드·TypeScript·ESLint·diff 공백 검사 통과

단위 테스트는 요약 3개·API 계약 4개·기존 알 순위 13개, 총 20개를 통과했다. Playwright는 순환 화면 10개·공통 메뉴 7개·업무 탭 9개, 총 26개를 통과했다. 페이지 이동 시 목록 위치 복귀와 마지막 조회 지역 복원 변경은 해당 항목을 다시 실행해 확인했다. 자동 접근성 검사는 전체 수동 접근성 인증을 의미하지 않는다.

검증은 격리 로컬 DB와 콘솔 문자 공급자 환경에서 진행했다. 실제 배정·문자 전송 없이 조회만 수행했다.
