# 기능별 UI/UX 검증 체크리스트

> 변경 전 154개 점검 기록입니다. 수정 후 결과는 [개선 및 재검증 체크리스트](IMPROVEMENTS.md)에 따로 기록했습니다.

검증 기준: 2026-09-10 작업 트리. 업체 5개, 기사 5개 화면을 대상으로 한다.

**표기:** 통과 = 해당 조건에서 실제 확인, 개선 = 재현된 문제 또는 사용성 개선 필요, 소스 확인 = 구현을 읽었지만 해당 분기의 종단 동작까지 검증하지 않음, 미검증 = 외부 환경·실기기 확인 필요. **B** 브라우저 실조작, **T** 기존 기능 테스트, **I** 오류·경계값 응답 주입, **S** 소스 검토. 통과는 해당 행의 조건에 한정하며 전체 접근성 인증을 뜻하지 않는다.
