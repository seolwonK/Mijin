1관리자 로그인

아이디 입력란을 클릭하고 발급받은 관리자 아이디를 입력합니다.
비밀번호를 입력합니다. 두 값을 채워야 로그인 버튼이 활성화됩니다.
로그인을 클릭합니다. 정상 로그인되면 관제탑 대시보드로 이동합니다.

로그인 오류 대응

  • 아이디 또는 비밀번호가 올바르지 않습니다: 입력값과 영문 대소문자를 다시 확인합니다.
  • 로그인이 필요합니다: 세션이 만료된 상태이므로 다시 로그인합니다.
  • 공용 PC에서는 업무 종료 후 오른쪽 위 로그아웃을 반드시 클릭합니다.
  • 비밀번호는 메신저·문서·브라우저 메모에 저장하지 않습니다.

3대시보드(관제탑)

  1. 상단 대시보드 탭입니다.
  2. 전체: 오늘 접수 전체를 표시합니다.
  3. 배정대기: 아직 배정되지 않은 접수만 표시합니다.
  4. 배정됨: 배정 제안 후 응답 대기 중인 접수를 표시합니다.
  5. 진행중: 수락·출동 단계의 접수를 표시합니다.
  6. 완료/취소: 종료 상태 접수를 표시합니다.
  7. 접수 검색: 접수번호·고객명·전화번호·내용으로 목록을 좁힙니다.
  8. 시각 열 제목: 클릭하면 정렬 방향이 바뀝니다.

요약 카드

  • 오늘 접수: 오늘 생성된 전체 접수 수. ★시간대별 미니 그래프(스파크라인)가 함께 표시됩니다.
  • 배정 대기: ★카드를 클릭하면 아래 목록이 배정대기 탭으로 바로 전환됩니다.
  • 진행중 / 완료·취소: 현재 단계별 접수 수입니다.
  • 긴급 미완료: 긴급도가 높고 종료되지 않은 접수. 붉은 숫자로 표시되며 클릭 시 분석 화면으로 이동합니다. 업무 시작 시 최우선 확인.
  • 분석 보기: 분석 현황 화면으로 이동합니다.

접수 목록 사용법

  1. 업무 목적에 맞는 상태 탭을 누릅니다. 탭에는 건수가 함께 표시됩니다.
  2. 필요하면 검색창에 접수번호나 고객 정보를 입력합니다.
  3. 행을 클릭하면 오른쪽에 요약 패널이 열립니다 — 상태·배정 이력 요약·설문 여부·추천 순위와 함께 상세 열기 링크가 제공됩니다.
  4. 배정대기 건은 요약 패널에서 바로 배정할 수 있습니다. 패널에 후보 목록이 그대로 나오므로 상세 화면을 열지 않고 배정을 눌러도 됩니다(확인창은 상세 화면과 같습니다).
  5. 빨간 확인요망 표시(빨간 행 배경)와 긴급 건은 우선 처리합니다. 확인요망 → 배정대기 → 나머지 순으로 목록 맨 위에 자동 정렬되므로, 시각 정렬을 바꿔도 이 순서는 유지됩니다.
  6. 목록은 주기적으로 자동 갱신되어 새 접수가 자동 반영됩니다.

4접수 상세

4-1. 기본 정보

  • 헤더: 접수번호·긴급도 배지·상태 배지. 뒤로가기로 목록 복귀.
  • 고장 내용·접수 시각·고객명·전화(누르면 전화 연결)·주소.
  • ★사진 갤러리: 고객이 첨부한 사진 썸네일. 크게 보기를 누르면 원본으로 확인합니다. 출동 전 상황 파악에 활용하세요.
  • ★음성 접수: 음성으로 접수된 건은 고객 음성 녹음 재생과 자동 변환 텍스트가 함께 표시됩니다.
  • 좌표가 있으면 지도에서 보기가 제공되고, 좌표가 없으면 주소만 표시됩니다(거리 미확인).

4-2. 배정 추천 순위 ★

  • 근거 순서: 거절이력 → 지역 → 알 보유량 → 30일 배정(전체) → 평균 별점 → 거리 순으로 후보를 줄 세웁니다.
  • 후보 카드 읽는 법: 업체/전기기사 구분, 거리(좌표 없으면 “거리 미확인”), 알 보유량, 30일 배정(수락+거절), 평균 별점(리뷰 수)이 한 카드에 표시됩니다.
  • 1순위 카드에는 자동배정 예정 배지가 붙고, 하위 후보에는 알 보유량에서 뒤짐·별점 우위 같은 순위 사유가 표시됩니다.
  • 자동배정 카운트다운: 자동배정까지 56:12처럼 남은 시간이 표시됩니다(배정 워커 주기 약 30초 오차). 시간이 다 되면 1순위에게 자동 배정됩니다. 자동배정이 꺼져 있으면 꺼짐 표시가, 후보가 없으면 후보 없음 안내가 나타납니다.

4-3. 수동 배정

상태가 배정대기인지 확인합니다.
후보 카드의 거리·알·평점·거절 이력을 비교해 대상을 고릅니다.
해당 카드의 배정을 클릭합니다.
확인창 ○○(업체)에게 이 접수를 배정할까요? 배정 안내 문자가 발송됩니다.에서 대상이 맞는지 확인하고 배정으로 확정합니다.
상태가 배정됨으로 바뀌고 배정 이력에 응답 대기 · 수동배정 행이 생겼는지 확인합니다.

배정 이력 읽는 법

  • 행마다 대상·연락처·응답 상태(응답 대기/수락/거절+사유)·수동/자동배정 구분·시각이 남습니다.
  • 회수·재배정을 해도 이력은 그대로 남아 어떤 업체가 응답하지 않았는지 추적할 수 있습니다.

4-4. 배정 회수

  • 업체(기사) 응답 대기 중일 때만 배정 회수가 나타납니다.
  • 회수 전 배정 이력에서 현재 응답 상태를 확인합니다.
  • 확인창 현재 배정을 회수하고 배정 대기로 되돌릴까요? 업체에는 회수 안내 문자가 발송됩니다.에서 회수를 누르면 접수가 배정대기로 돌아갑니다.
회수하면 접수는 배정대기로 돌아가고, 회수한 대상은 이 접수의 자동 재선택에서 제외됩니다. 몇 분 안(설정 대기시간: 초긴급 2·긴급 3·일반 5분)에 안전망이 다음 순위에게 자동 배정하므로, 특정 대상에게 주려면 회수 직후 바로 수동 배정하세요. 상세 원리는 별도 「배정 로직 상세 문서」 참고.

4-5. 접수 취소

  • 완료 전 상태에서 화면 맨 아래 접수 취소를 사용할 수 있습니다.
  • 확인창 이 접수를 취소할까요?에서 접수 취소로 확정하면 상태가 취소로 바뀝니다.
  • 취소는 운영 이력과 통계에 바로 반영됩니다. 고객 요청 또는 명확한 오접수일 때만 실행합니다.
취소는 아무에게도 문자로 알리지 않습니다. 배정 회수와 달리 수락·출동 중인 업체·전기기사에게도, 고객에게도 통지가 가지 않습니다. 이미 배정된 건을 취소했다면 반드시 해당 업체에 전화로 알리십시오. 현장 출동이 진행 중일 수 있습니다.

4-6. 만족도 조사

  • 완료 건의 만족도 조사 결과가 접수 상세 하단에 모입니다: 발송/미발송·제출/미참여 상태, 별점, 후기, 고객 신고 지불 금액.
  • 이 지불 금액이 정산 집계 리포트의 원천입니다(10장).

5업체 관리

  1. 상단 업체 관리 탭. 숫자 배지 = 승인 대기 업체 수.
  2. + 직접 등록: 관리자가 업체 계정을 직접 만듭니다(5-3).
  3. 승인 대기 카드: 클릭하면 신청 정보·증빙 검토 화면으로 이동합니다.
  4. 업체명 열: 클릭해 정렬합니다.
  5. 전화 열: 전화번호 기준 정렬.
  6. 업체명을 클릭하면 상세 화면으로 이동합니다.
  7. 활성 버튼: 누르면 비활성 전환 확인창이 열립니다.
  8. 거절된 신청은 목록 하단 거절된 신청에 사유와 함께 남습니다.

승인 회수와 비활성의 차이

조치효력
승인을 거절로 변경이미 로그인해 있던 세션도 다음 요청부터 차단됩니다. 포털에 접속하면 로그인 화면으로 밀려나고 거절 사유가 표시됩니다.
비활성 전환로그인과 포털 이용은 그대로 두고 배정 후보에서만 제외합니다. 진행 중인 건은 유지됩니다.
활성 버튼은 단순 표시가 아니라 운영 상태를 즉시 변경합니다. 실수로 누른 경우 확인창에서 취소하십시오. 활성 → 비활성 전환에만 확인창이 있고, 비활성 → 활성은 확인창 없이 즉시 반영됩니다.

5-1. 가입 심사 — 승인·거절

  1. 업체 관리로 돌아갑니다.
  2. 이동 경로의 업체 관리 링크입니다.
  3. 현재 업체명과 상세 화면 위치입니다.
  4. 뒤로가기입니다.
  5. 원본 크게 보기: 첨부된 증빙 원본을 크게 확인합니다.
  6. 가입 승인: 대조를 마친 뒤 승인합니다.
  7. 거절: 거절 사유 입력 폼을 엽니다. 사유를 구체적으로 쓰고 거절 확정을 누릅니다. 사유는 신청자가 로그인할 때 표시됩니다. 사유는 비워도 거절되지만(최대 200자) 재신청 안내를 위해 반드시 적으십시오. 거절 버튼은 승인 대기 상태에서만 나타납니다.
  8. 지정/변경/해제: 소개자를 지정·변경하거나 해제합니다. 전화번호로 조회하며 승인·활성 회원만 검색되고 본인은 지정할 수 없습니다. 소급 지정 시 과거 조사는 적립되지 않습니다.

거절한 신청을 다시 승인하려면

거절된 신청도 상세 화면에서 그대로 다시 승인할 수 있습니다. 신청자가 재신청할 때까지 기다릴 필요가 없습니다. 목록 하단 거절된 신청 카드를 클릭해 상세로 들어간 뒤 가입 승인을 누르면 되고, 승인 시 거절 사유는 지워집니다.

승인 전 필수 확인

  • ★증빙 2종: 사업자등록증 + 전기공사업 등록증이 모두 첨부·판독 가능한지. (전기공사업 등록증 필수 도입 전 가입 업체는 없음 안내가 표시됩니다)
  • 등록증의 상호와 신청 업체명이 일치하는지, 사업자등록번호가 식별되는지.
  • 연락처 형식과 주소·서비스 지역이 실제 영업 범위와 맞는지.
  • 좌표: 좌표가 없으면 화면에 좌표가 없어 거리순 정렬은 안 되지만, 서비스 지역이 설정돼 있으면 지역 기준으로 자동배정됩니다. 정확한 거리 배정을 원하면 아래에서 좌표를 입력하세요. 안내가 표시됩니다. 정확한 거리 배정을 원하면 주소 입력 후 좌표 변환을 수행하세요.
좌표가 없는 대상을 승인하면 브라우저 확인창이 한 번 더 뜹니다: 좌표가 없는 업체입니다. 서비스 지역이 설정돼 있으면 지역 기준으로 자동배정되며, 좌표를 입력하면 거리순 배정까지 됩니다. 그래도 승인할까요? 확인을 누르면 승인되고, 취소하면 승인되지 않습니다.

5-2. 정보 수정

상세 화면 아래에서 계정(아이디 조회만·비밀번호는 변경 시만 입력)·업체 정보·전화·주소·좌표 변환·위도/경도 직접 입력·메모를 수정하고 수정 저장을 누릅니다. 즉시 반영되며, 저장하면 자동으로 업체 관리 목록 화면으로 돌아갑니다.

서비스 가능 지역은 관리자가 바꿀 수 없습니다. 상세 화면에 지역 입력란이 없습니다. 담당 지역 조정이 필요하면 업체가 직접 포털 → 내 정보 → 서비스 가능 지역에서 수정하도록 안내하십시오. 전기기사는 포털에 내 정보 화면이 없으므로 지역 변경 요청을 받으면 별도로 처리해야 합니다.

5-3. 업체 직접 등록

  1. 뒤로가기로 목록으로 돌아갑니다.
  2. 추천인 전화번호: 소개자가 있으면 입력합니다.
  3. 확인: 추천인 조회 결과를 확인합니다.
  4. 로그인 아이디: 중복되지 않게 입력합니다.
  5. 비밀번호: 8자 이상.
  6. 업체명 입력.
  7. 전화번호 입력.
  8. 주소·좌표·메모 입력 후 화면 아래 업체 등록을 누르면 운영 중 목록에 바로 반영됩니다.
직접 등록 폼에는 사업자등록번호와 서비스 가능 지역 입력란이 없습니다. 그래서 이렇게 만든 업체는 서비스 지역이 비어 전 지역 담당으로 동작하며, 모든 지역의 접수에서 배정 후보로 잡힙니다. 담당 지역을 좁히려면 업체가 로그인해 내 정보에서 직접 등록해야 합니다. 아이디는 3자 이상이면 되고, 등록 즉시 승인 상태가 됩니다(심사 없음).

주소와 좌표

  1. 주소를 도로명 또는 지번 형식으로 입력하고 좌표 변환을 클릭합니다.
  2. 위도·경도가 채워졌는지 확인합니다. 변환에 실패하면(좌표를 직접 입력해 주세요) 주소를 정정하거나 위도·경도를 직접 입력합니다.

6전기기사 관리

  1. 상단 전기기사 관리 탭입니다.
  2. + 직접 등록: 관리자가 기사 계정을 만듭니다(6-3).
  3. 이름 열 정렬.
  4. 전화 열 정렬.
  5. 이름을 클릭하면 상세 화면으로 이동합니다.
  6. 활성 버튼으로 배정 후보 포함/제외를 전환합니다(확인창).
  7. 다른 기사도 같은 방식으로 확인합니다.
  8. 행 오른쪽에서 활성 상태를 확인합니다.

근로확인 상태

상태의미
미작성기사가 근로확인서를 시작하지 않음. 직접 등록 직후 기본 상태.
서명 전작성 중이거나 서명이 없음 — 배정 불가.
확정 대기 (관리자 확인 필요)목록에 이 라벨이 준비돼 있으나, 기사가 서명하면 곧바로 서명 완료로 넘어가므로 실제로는 나타나지 않습니다.
서명 완료 (배정 가능)서명까지 완료 — 배정 가능.
전기기사가 배정 후보가 되려면 승인 + 활성 + 서명 완료 세 가지가 모두 필요합니다. 가입 심사가 아니라 근로확인서 서명이 실질적인 관문입니다.

6-1. 전기기사 상세

  • 승인 상태와 신청 시각, 근로 형태(일일/상시), 성명·전화·주소·좌표, 소개자, 평균 평점·후기를 관리합니다.
  • 근로확인서 열기로 작성·서명 상태를 확인합니다(6-2).
  • 아이디는 조회만 가능하고, 비밀번호는 재설정할 때만 새 값을 입력합니다. 근로 형태(일일/상시)는 이 화면에서 변경할 수 있습니다.
  • 알 크레딧 섹션은 7장과 동일한 방식으로 사용합니다.
전기기사에게는 가입 심사 단계가 없습니다. 셀프 가입은 휴대폰 본인인증을 마치는 즉시 승인되어 자동 로그인되고, 관리자 직접 등록도 즉시 승인 상태로 만들어집니다. 승인 대기 상태의 기사가 생기지 않으므로 승인 대기 카드에 기사가 나타나지 않고, 화면의 가입 승인·거절 버튼도 실제로는 쓰이지 않습니다(거절은 승인 대기 상태에서만 동작). 기사의 배정 가능 여부는 근로확인서 서명으로 갈립니다 — 서명 전에는 승인·활성 상태여도 배정 후보에 들어가지 않습니다. 활동을 막아야 할 기사는 거절이 아니라 비활성으로 전환하십시오.

6-2. 근로확인서 확인·인쇄

기사 서명 이미지와 서명 시각을 확인합니다.
계약기간(기간의 정함이 없음)·근무장소·업무 내용·근무일·소정근로시간·주휴일을 확인합니다.
임금 형태(월급/일급/시급)와 금액·상여금·기타 항목(예: 식대)을 확인·보정합니다.
4대보험(고용·산재·국민연금·건강) 체크와 임금지급일·지급방법(예금통장/직접)을 확인합니다.
사업주 정보가 설정(12장)과 연동돼 자동 기입됐는지 확인합니다.
임금 저장을 누르면 저장했습니다가 표시됩니다.
인쇄 화면에서 출력 형태를 확인하고 브라우저 인쇄로 출력 또는 PDF 저장합니다.
기사가 서명을 완료한 뒤에는 전 항목이 읽기 전용으로 바뀌어 조회·인쇄만 가능합니다. 저장을 시도하면 전기기사가 서명 완료한 근로확인서는 수정할 수 없습니다로 거부됩니다.
임금을 보정할 시간이 거의 없습니다. 기사는 가입 직후 설정(12장)의 기본 임금이 채워진 상태로 곧바로 서명할 수 있고, 서명하면 그 값으로 확정됩니다. 개별 조건을 협의해야 하는 기사에게는 서명 전에 미리 연락해 대기시킨 뒤 임금을 입력하십시오. 이미 서명된 확인서를 고쳐야 한다면 새 조건으로 다시 작성해야 합니다.

6-3. 전기기사 직접 등록

  • 추천인(선택)·아이디·비밀번호(8자+)·근로 형태(일일/상시)·성명·전화·주소·좌표·메모를 입력하고 전기기사 등록을 누릅니다.
  • 등록 직후 근로확인은 미작성 상태로 시작합니다 — 기사가 로그인해 서명해야 배정 가능해집니다.
  • 등록 즉시 승인 상태가 되며 별도 심사 단계는 없습니다.
관리자 직접 등록은 휴대폰 본인인증을 거치지 않습니다. 셀프 가입에만 본인인증 관문이 있습니다. 직접 등록으로 만든 계정은 성명·전화번호가 관리자 입력값 그대로이므로, 신분증·자격 확인을 별도로 마친 뒤에만 등록하십시오. 서비스 가능 지역 입력란도 없어 전 지역 담당으로 시작합니다.

7알 크레딧 관리 ★

알은 업체·기사의 배정 노출 순위에 쓰이는 크레딧입니다. 관리는 업체 상세·기사 상세 화면의 알 크레딧 섹션에서 합니다(두 화면 동일 UI).

7-1. 규칙 요약

항목규칙
수락 차감업체·기사가 배정을 수락하면 1알 자동 차감. 잔액 0알이어도 수락은 막히지 않고 차감 없이 처리됩니다.
충전최소 3알 · 1알 = ₩1,000. 알 수를 바꾸면 결제 금액이 자동 계산됩니다. 사유 입력이 필수(예: “8/31 무통장 입금 3알 확인”)이며, 입금 확인 후에만 처리합니다. 충전 버튼은 사유를 입력해야 활성화되고, 누르면 확인창 없이 즉시 반영됩니다.
정정양수 = 증액 · 음수 = 감액. 잔액보다 큰 감액은 불가. 사유 필수. 오충전 환불 등에 사용합니다.
노출 순위알이 많을수록 배정 추천·자동배정 순위에서 우선됩니다. 순환 현황(8장)의 알 보유 열과 접수 상세의 추천 순위에 반영됩니다.

7-2. 충전 처리 절차

업체(기사) 상세를 열고 알 크레딧 섹션으로 이동해 현재 잔액을 확인합니다.
충전할 알 수를 입력하고 자동 계산된 결제 금액과 입금액이 일치하는지 확인합니다.
충전 사유를 어떤 입금 건인지 알 수 있게 구체적으로 입력합니다.
충전을 누릅니다. 즉시 잔액이 늘고 변동 이력 맨 위에 기록이 생깁니다.
충전은 확인창 없이 즉시 반영됩니다. 입금 확인 전에는 누르지 마세요. 잘못 충전했다면 정정(음수)으로 바로잡고 사유를 남기세요.
화면이 느려 충전 버튼을 두 번 눌러도 중복 충전되지 않습니다. 같은 입력 건은 한 번만 반영되도록 막혀 있습니다. 다만 금액을 바꿔 다시 누르면 별개 충전으로 처리되니, 반영 여부는 항상 변동 이력으로 확인하십시오.

8순환 현황

시/도를 선택합니다(필요하면 시/군/구까지).
지역→알 보유량→30일 순환 (URGENT·NORMAL 공통 사슬) 기준의 후보 순위를 확인합니다.
총 후보 수·30일 배정 합계·평균 별점 요약과, 순위표의 순위·이름·종류·★알 보유·30일 배정(전체)·평균 별점·후기 수를 비교합니다.

해석 주의사항

  • 표의 순위는 일반·긴급 접수의 예상 자동배정 순서입니다. 동률이면 실제 거리로 최종 순서가 달라질 수 있습니다.
  • 초긴급(CRITICAL)은 거리 우선이므로 이 순번을 그대로 사용하지 않습니다.
  • 확인용 화면이며 순서를 직접 편집할 수 없습니다. 순위에 영향을 주려면 알 충전(7장)이나 활성 상태를 조정하십시오. 서비스 가능 지역은 관리자가 바꿀 수 없으므로(5-2 참고) 담당 지역 조정이 필요하면 업체에 직접 수정을 요청해야 합니다.
  • 이 화면은 가로 1024px 이상에서만 열립니다. 좁은 화면에서는 데스크톱 이용 안내만 표시됩니다.

확인창의 소개자명·금액을 다시 확인하고 확정합니다.
미지급 합계·지급 누계가 갱신됐는지 확인합니다.
지급 완료 처리는 회계 상태를 변경합니다. 실제 이체 확인 전에는 누르지 마십시오.
소개자 이름 옆의 「비활성」 배지는 그 소개자 계정이 현재 비활성 상태라는 뜻입니다. 배지가 붙어 있어도 이미 적립된 수수료는 지급해야 합니다. 확인창은 선택 지급이면 선택한 N건을 지급 완료로 처리할까요?, 전액 지급이면 ○○의 미지급 N원 전액을 지급 완료로 처리할까요?로 표시됩니다.

11분석 4종

상단 분석을 클릭하면 현황·지도·설문·평점 하위 메뉴가 열립니다.

11-1. 현황

  • 일/주/월 버튼으로 집계 기간을 전환합니다. 처음 열면 「주」가 선택되어 있습니다.
  • 운영 상태(완료·취소·접수·배정), 확인 요망, 긴급도 분포, 접수·완료 추이를 확인합니다.
  • 배정 퍼널: 최초 제안까지 시간 · 응답완료 제안 수락률 · 최종 수락까지 시간 · 접수 단위 성공률.
  • 돈 흐름: 설문 결제 합계·평균, 수수료 대기·지급 금액.
  • 각 지표의 ? 산식 안내에서 분모·분자 기준을 확인합니다.

11-2. 지도

  • 갭 경보: 수요는 있는데 활성 공급자가 없는 지역을 우선 표시합니다.
  • 수요 = 최근 1개월간 취소되지 않은 접수 수입니다. 미완료 건만이 아니라 이미 완료된 건도 포함됩니다 — 그 지역에서 최근 얼마나 일이 들어왔는지를 보는 숫자입니다.
  • 공급 = 배정 가능한 활성 업체·기사 수. 단, 서비스 가능 지역을 비워 둔 전 지역 담당 업체는 지역별 공급 계산에서 제외됩니다. 그래서 실제로는 출동 가능한 지역인데도 공급 0으로 잡힐 수 있습니다.
  • 압력 = 수요 ÷ 공급(높을수록 공급 부족).
  • 드릴다운: 순위표의 시/도를 클릭하면 그 지역의 시/군/구 단위로 내려갑니다. 행정경계 지도 데이터가 준비되지 않은 환경에서는 지도 대신 순위표만 제공된다는 안내가 표시됩니다.
  • 위치 미상: 주소·좌표로 지역을 판별하지 못한 접수. 출동 현황은 차량 GPS가 아니라 고객 목적지 기준이며 8초마다 갱신됩니다.
  • 화면의 마지막 갱신 시각으로 데이터 신선도를 판단합니다.

11-3. 설문

  • 응답률(발송 대비 제출)과 제출/발송 건수를 확인합니다. 설문 미발송과 미제출을 구분하세요.
  • 응답률이 낮으면 미제출 목록(접수번호·고객명·전화·경과일)에서 후속 안내 대상을 찾습니다. 목록은 오래된 순으로 50건까지만 표시되고 나머지는 외 N건으로만 표기됩니다. 더보기가 없으므로 50건을 처리해야 다음이 드러납니다.
  • 결제 통계는 고객이 설문에 입력한 금액 기준(합계·건수·평균)입니다.
  • 개인정보가 포함되므로 미제출 목록을 외부 파일로 복사하지 않습니다.

11-4. 평점

이름 검색·정렬(이름/유형/평균 별점/응답 수/완료 건수)로 대상을 찾습니다.
행을 클릭하면 아래 평점 상세에 월별 별점 추이 차트와 개별 후기·완료 실적이 표시됩니다. 추이로 최근 평점이 떨어지는 대상을 조기에 찾을 수 있습니다.
탈퇴·삭제된 대상의 후기는 이름 대신 삭제된 대상으로 표시됩니다.
평균 별점만 보지 말고 응답 수·완료 건수를 함께 봅니다. 응답 수가 적은 고평점은 표본 부족일 수 있습니다.
민원 대응 시 원문 후기는 운영 목적 범위에서만 사용합니다.

항목내용

  3. 자동배정 토글은 확인창의 변경 방향을 다시 읽고 확정합니다.

13일일 운영 권장 순서

업무 시작

  1. 로그인 후 대시보드의 긴급 미완료와 배정대기를 확인합니다.
  2. 업체 관리·전기기사 관리의 승인 대기 배지를 확인합니다.
  3. 순환 현황에서 주요 서비스 지역의 후보 부족 여부를 확인합니다.
  4. 분석 현황의 확인 요망을 확인합니다.

업무 중

  1. 배정대기 접수를 긴급도 순으로 처리합니다. 자동배정 카운트다운을 기다릴지, 수동 배정할지 판단합니다.
  2. 배정 응답이 지연되면 접수 상세에서 회수 여부를 판단합니다.
  3. 신규 업체·기사 신청을 증빙 2종과 연락처 기준으로 심사합니다.
  4. 기사 근로확인서의 서명·사업주 정보·임금 정보를 확인합니다.
  5. 알 충전 요청은 입금 확인 후 사유와 함께 처리합니다.
  6. 지급 처리 전 실제 이체 자료와 수수료 내역을 대조합니다.
  7. 대시보드의 빨간 확인요망 행을 최소 시간당 1회 확인합니다. 문자 발송이 중단된 기간에는 확인요망 문자가 오지 않으므로 화면 확인이 유일한 감지 수단입니다(15-1).

주 1회 점검

  1. 좌표 없는 업체·기사를 찾아 채웁니다. 업체 관리·전기기사 관리 목록에서 상세로 들어가 좌표 변환을 한 번 눌러 위도·경도를 채웁니다. 좌표가 없으면 배정 사슬의 거리 단계에서 뒤로 밀리고, 거절이 나도 다음 후보로 자동 승계되지 않습니다.
  2. 신규 가입과 정보 수정은 저장할 때 자동으로 좌표가 채워집니다 — 손이 필요한 것은 그 전에 만들어진 기존 계정입니다.
  3. 순환 현황에서 서비스 지역별 후보 수를 확인하고, 공급이 부족한 지역은 분석 → 지도의 갭 경보와 함께 봅니다.

업무 종료

  1. 미완료 긴급 접수와 확인 필요 건을 인계합니다.
  2. 정산 처리 건의 합계와 지급 자료를 대조합니다.
  3. 설정을 변경했다면 변경 전후 값을 기록합니다.
  4. 오른쪽 위 로그아웃을 클릭합니다.

14실수 방지 체크리스트

  • ☐ 승인/거절 대상의 이름과 유형을 다시 확인했다.
  • ☐ 증빙 2종(사업자등록증·전기공사업 등록증)을 모두 원본 크게 보기로 확인했다.
  • ☐ 거절 사유는 신청자가 이해할 수 있게 구체적으로 작성했다.
  • ☐ 활성/비활성 전환이 배정 후보에 미치는 영향을 확인했다.
  • ☐ 배정 확정 전 확인창의 대상 이름을 읽었다.
  • ☐ 배정 회수 전 현재 응답 상태와 배정 이력을 확인했다.
  • ☐ 접수 취소 전 고객 요청 또는 오접수 근거를 확인했다.
  • ☐ 배정된 접수를 취소한 뒤 해당 업체에 전화로 알렸다(취소는 문자가 발송되지 않는다).
  • ☐ 알 충전은 입금 확인 후, 사유를 남기고 처리했다.
  • ☐ 지급 완료 전 실제 이체 여부와 금액을 확인했다.
  • ☐ 설정 저장 후 새로고침으로 반영 여부를 확인했다.
  • ☐ (주 1회) 업체·기사 목록에서 좌표 없는 계정을 찾아 좌표 변환으로 채웠다.
  • ☐ (문자 중단 기간) 확인요망 문자를 기다리지 않고 대시보드의 빨간 행을 직접 확인했다.
  • ☐ 고객 전화번호·주소·후기 등 개인정보를 외부에 공유하지 않았다.
  • ☐ 업무 종료 후 로그아웃했다.

15문제 해결

증상확인 및 조치
목록이 비어 있음선택한 상태 탭·검색어·월 필터를 초기화하고 새로고침합니다.
승인이 되지 않음필수 정보·증빙 2종·승인 상태·오류 메시지를 확인합니다.
자동배정 후보가 없음대상 지역, 활성 상태, 승인 상태, 좌표/서비스 지역, 기사 근로확인 완료 여부를 확인합니다.
거리순 정렬이 이상함 / “거리 미확인”업체·기사 주소를 좌표 변환했는지 확인합니다. 좌표가 없으면 거리 배정 대신 지역 기준으로 동작합니다.
회수했는데 곧바로 같은 업체에 재배정됨자동배정이 켜져 있고 대기시간이 이미 지난 접수는 워커가 다시 1순위에 배정합니다. 회수 후 곧바로 수동 배정하거나 자동배정 설정을 확인하세요.
정산 금액이 다름정산 월, 고객 설문 지불금액 입력 여부(커버리지), 지급 상태를 확인합니다.
안내 문자가 발송되지 않음문자 발송사 연동 상태를 확인합니다. 관리자 화면에는 문자 발송 기록을 조회할 수 있는 메뉴가 없습니다 — 발송 성공 여부는 서버 기록으로만 확인되므로, 중요한 건은 화면에서 상태를 확인한 뒤 전화로 직접 안내하는 것을 기본 절차로 삼으십시오. 발송이 중단된 기간의 대체 절차는 아래 15-1을 따릅니다.
취소했는데 업체가 계속 출동함접수 취소는 문자를 발송하지 않습니다. 배정된 업체에 전화로 직접 알려야 합니다(4-5).
기사 승인 대기가 보이지 않음정상입니다. 전기기사는 가입 즉시 승인되어 승인 대기 상태가 생기지 않습니다(6-1). 배정 여부는 근로확인서 서명으로 갈립니다.
분석·순환 현황 메뉴가 없음브라우저 창 가로 폭이 1024px 미만입니다. 창을 넓히거나 데스크톱에서 접속하세요.
분석 수치가 바로 안 바뀜화면의 마지막 갱신 시각을 확인하고 잠시 후 새로고침합니다.
저장 버튼이 비활성필수 입력값(예: 충전 사유), 숫자 형식, 비밀번호 최소 길이를 확인합니다.
로그인 상태가 풀림세션 만료입니다. 다시 로그인합니다.

15-1. 문자 발송이 중단됐을 때의 대체 절차

문자 발송사(SOLAPI) 연동이 2026-08-13부터 전면 실패 중입니다. 아래 문자가 모두 발송되지 않습니다 — 고객 접수 완료 · 고객 만족도 조사 링크 · 업체 배정 안내 · 업체 회수 안내 · 관리자 확인요망. 발송 실패는 서버 기록에만 남고 관리자 화면에서는 확인할 수 없으므로, 연동이 복구될 때까지 아래를 기본 운영으로 삼으십시오.
확인요망 문자를 기다리지 마십시오. 대시보드의 빨간 확인요망 행을 주기적으로(최소 시간당 1회) 직접 확인합니다. 확인요망 행은 목록 맨 위로 자동 정렬되므로 대시보드를 열기만 하면 바로 보입니다.
배정 직후 업체에 전화로 확인합니다. 업체는 배정 안내 문자를 받지 못하므로, 포털 화면을 열어 두지 않았다면 배정 사실 자체를 모릅니다. 10분 안에 응답이 없으면 자동 회수되어 다음 순위로 넘어갑니다.
완료 건 고객에게는 만족도 조사 링크가 가지 않습니다. 고객이 전기아저씨.com → 조회에서 접수 전화번호로 조회하면, 완료된 접수 카드의 만족도 조사 참여 버튼으로 직접 참여할 수 있습니다. 이 경로를 안내하십시오.
접수를 취소하면 반드시 전화로 통보합니다. 접수 취소는 문자 발송사 상태와 무관하게 원래도 문자를 보내지 않습니다(4-5). 수락·출동 중인 접수를 취소했다면 업체가 그대로 출동할 수 있습니다.
고객 문의가 늘어날 수 있습니다. "접수 확인 문자가 안 왔다"는 문의에는 접수번호와 진행 상황을 화면에서 확인해 구두로 안내하고, 조회 화면 사용법을 함께 알려 주십시오.

15-2. 운영 개시 전 정리

최초 배포 시 RUN_DB_SEED=1로 만든 시드 계정과 정산 데모 데이터가 운영 DB에 남아 있으면 업체 목록·순환 현황·정산 화면에 실제 데이터와 섞여 보입니다. 운영을 시작하기 전에 아래를 정리하십시오.

시드 업체·기사 계정을 정리합니다. 업체 관리·전기기사 관리 목록에서 시연용 계정을 찾아 비활성으로 돌리거나 삭제합니다. 비활성으로만 두어도 배정 후보에서는 빠집니다.
정산 화면에 시연용 금액이 보이면 시드 데이터인지 확인합니다. 실제 이체와 대조되지 않는 적립 건은 지급 처리하지 마십시오.
확인요망 문자 수신 번호를 실제 번호로 맞춥니다. 시드 관리자 계정의 전화번호는 01000000000 더미 값이라 그대로 두면 확인요망 문자가 아무에게도 도달하지 않습니다. 환경변수 ADMIN_ALERT_PHONES에 담당자 번호를 넣거나(쉼표로 여러 명), 관리자 계정의 전화번호 자체를 고칩니다.
최초 기동 후 RUN_DB_SEED를 0으로 되돌립니다. 첫 로그인 비밀번호(admin/admin1234)도 반드시 변경하십시오.
