문의 전화: 070-4995-3910
이 문서의 화면은 실제 서비스 화면을 기준으로 작성되었습니다. 화면 속 고객 정보는 시연용 데이터입니다.

목차

  1. 가입 신청계정 · 근로 형태 · 휴대폰 본인인증 · 주소·지역 · 가입 즉시 이용

  3. 홈 화면 안내요약 · 내 알 · 응답 대기 · 내 성과 · 받은 후기
  4. 배정 수락부터 완료까지상세 확인 · 수락 · 출동 · 완료 확정
  5. 성과와 수수료 확인
  6. 자주 묻는 문제

1가입 신청

전기아저씨.com → 기사 포털 → 가입 신청으로 들어갑니다. 신청서는 계정 정보 → 근로 형태 → 전기기사 정보(본인인증) → 주소·서비스 지역 → 추천인(선택) → 동의 순서로 채웁니다.

1-1. 계정 정보

로그인 아이디(3자 이상 30자 이하)를 입력하고 중복 확인을 누릅니다. 사용할 수 있는 아이디입니다가 나오면 통과입니다.
비밀번호(8자 이상)와 비밀번호 확인을 입력합니다. 표시 버튼으로 입력값을 확인할 수 있습니다.

1-2. 근로 형태 선택

형태의미
일일 근로자하루 8시간 단위로 근로하는 형태입니다.
상시 근로자평일 09:00~18:00 기준 상시 근로 형태입니다(추후 협의로 변동 가능).

선택한 근로 형태는 가입 후 작성하는 근로확인서의 기본값으로 이어집니다. 실제 계약 조건은 이후 관리자와 협의해 조정됩니다.

1-3. 전기기사 정보와 휴대폰 본인인증

성명과 전화번호를 본인 명의 그대로 입력합니다.
본인인증을 누르면 휴대폰 본인확인 창이 열립니다. 통신사를 선택하고 문자로 받은 인증번호를 입력해 인증을 마칩니다.
인증이 끝나면 성명·전화번호가 인증된 값으로 채워지고 읽기 전용이 됩니다. 다른 번호로 다시 인증하려면 옆의 변경을 누릅니다.
기기인증 창이 열리는 방식
PC작은 팝업 창이 열립니다. 팝업이 차단돼도 그대로 진행됩니다 — 차단이 감지되면 같은 탭이 인증 화면으로 전환되고, 인증을 마치면 가입 화면으로 돌아옵니다.
휴대폰화면 전체가 인증 페이지로 넘어갔다가 인증 후 가입 화면으로 돌아옵니다. 입력해 둔 내용은 그대로 복원되지만 비밀번호만 다시 입력해야 합니다(보안상 저장하지 않습니다). 화면에도 본인인증을 마치고 돌아왔습니다. 보안을 위해 비밀번호는 다시 입력해 주세요. 안내가 나옵니다.
본인인증을 완료해야 가입 신청이 가능하고, 인증 후 10분 안에 가입 신청을 마쳐야 합니다. 10분이 지나면 본인인증 유효시간이 지났습니다. 다시 인증해 주세요.가 표시됩니다. 인증 1건은 가입 1회에만 쓸 수 있습니다. 인증 정보(이름·전화번호)와 입력값이 다르면 인증이 실패합니다.

1-4. 주소·서비스 지역, 동의와 신청

주소의 시/도·시/군/구를 고르고 상세 주소를 입력합니다. 거리 기반 배정에 사용됩니다.
거주 시/도를 처음 고르면 서비스 가능 지역에 그 시/도(전체)가 자동으로 한 건 추가됩니다. 필요 없으면 칩의 ×를 눌러 빼면 됩니다.
서비스 가능 지역을 고르고 추가를 누릅니다. 여러 지역을 추가할 수 있고, 등록한 지역의 접수만 배정됩니다.
추천인이 있으면 전화번호로 조회해 지정합니다(가입 시에만 지정 가능).
이용약관·개인정보 동의에 체크하고 가입 신청하기를 누릅니다.

신청 후 흐름

  1. 전기기사 가입은 관리자 승인을 기다리지 않습니다. 신청이 끝나면 가입이 완료되었습니다 / 자동으로 로그인되었습니다 화면이 나오고, 그 자리에서 바로 로그인된 상태가 됩니다.
  2. 같은 화면의 근로확인서 작성하러 가기를 누르면 곧바로 서명 화면으로 이동합니다. 나중에 하려면 나중에 하기 (전기기사 포털로)를 누릅니다.
  3. 근로확인서에 서명해야 배정을 받을 수 있습니다(2장). 서명 전까지는 로그인은 되지만 배정 후보에 들어가지 않습니다.
가입할 때 만든 아이디·비밀번호는 다음 접속부터 필요합니다. 잊지 않도록 기록해 두세요.

2가입 직후 근로확인서 서명

가입을 마치면 완료 화면의 근로확인서 작성하러 가기로 바로 서명 화면에 들어갈 수 있습니다. 건너뛰었더라도 포털 홈 위쪽에 근로확인서 작성 필요 안내 배너가 남아 있으니 그 배너로 들어가면 됩니다. 서명을 완료하기 전에는 배정을 받을 수 없으므로 가입한 날 바로 처리하는 것을 권장합니다.

2-1. 작성 화면 확인

홈의 근로확인서 안내 배너를 눌러 작성 화면을 엽니다.
근로개시일·근무장소·업무 내용이 미리 채워져 있습니다. 실제와 다르면 직접 고칠 수 있습니다.
아래로 내려 근로자 정보(성명·주소)를 확인합니다. 임금 항목은 기본값으로 설정되어 있어 바로 서명할 수 있고, 실제 조건은 이후 관리자가 확인·조정합니다.

2-2. 서명과 제출

서명란에 마우스(PC) 또는 손가락(모바일)으로 본인 서명을 그립니다. 클릭만 해서는 그려지지 않고, 누른 상태로 끌어서 그립니다.
잘못 그렸으면 지우기를 누르고 다시 그립니다.
서명하고 완료를 누르면 근로확인이 끝나고, 배정 가능 상태가 됩니다.
서명 완료 후에는 근로확인서가 읽기 전용으로 바뀝니다. 내용 수정이 필요하면 관리자에게 문의하세요. 홈의 근로확인서 서명 완료 — 보기 → 배너에서 언제든 다시 열람할 수 있습니다.

3-1. 알림에 관해 알아두실 점

새 배정 브라우저 알림 켜기를 눌러 권한을 허용해 두면 도움이 되지만, 알림만 믿고 포털을 닫아 두면 안 됩니다.

  • 포털 탭을 열어 둔 동안에는 새 배정이 오면 알림음과 진동이 울리고, 탭 제목에 (1)처럼 대기 건수가 표시됩니다. 실제로 믿을 수 있는 것은 이 세 가지입니다.
  • 포털 탭을 닫거나 화면을 끄면 새 배정을 확인하지 못합니다. 이 상태에서는 브라우저 알림도 오지 않습니다.
10분이 지나면 배정이 자동 회수되므로, 일하는 동안에는 기사 포털 탭을 열어 두시기 바랍니다.

4배정 수락부터 완료까지

4-1. 배정 상세 확인

  • 경과 배너: 배정 후 경과 시간과 고객 응대 목표(초긴급 1시간·긴급 2시간·일반 순차)를 보여줍니다. 이 시간과 별개로 수락·거절 응답 자체는 10분 안에 해야 하며, 넘기면 배정이 자동 회수됩니다.
  • 고장 내용·고객 첨부 사진: 사진은 눌러서 원본 크기로 확인합니다. 출동 전 자재 준비에 활용하세요.
  • 위치: 주소와 지도 보기·길찾기(카카오맵). 고객: 이름과 바로 전화 버튼.
  • 버튼 위 안내: 수락하면 알 1개가 차감됩니다 (잔액이 없으면 차감 없이 수락)

4-2. 수락 → 출동 → 완료

내용을 확인하고 수락하기를 누릅니다. 확인창 없이 즉시 수락되고, 알 1개가 차감됩니다(0알이면 무차감). 어려우면 거절을 누릅니다 — 거절 사유는 선택 입력(200자)이라 비워 두고 거절 확정을 눌러도 됩니다.
현장으로 출발할 때 출동 시작 → 확인창 출동을 시작할까요?에서 다시 출동 시작.
작업이 끝나면 완료 처리 → 확인창 완료 처리할까요? 되돌릴 수 없습니다.에서 완료 확정.
완료는 되돌릴 수 없습니다. 실제 작업 종료 후에만 누르세요. 완료되면 고객 만족도 조사가 이어지고 별점·후기가 내 평점에 쌓입니다. 잦은 거절은 배정 순위 산정에 불리합니다.
거절한 접수가 항상 곧바로 다음 사람에게 넘어가지는 않습니다. 자동 배정된 건이면서 위치가 확인된 다음 후보가 남아 있을 때만 즉시 넘어가고, 관리자가 직접 배정한 건이거나 접수에 위치 정보가 없으면 배정 대기로 돌아가 관리자가 판단합니다.
수리 대금은 플랫폼을 거치지 않고 현장에서 고객과 직접 정산합니다.

5성과와 수수료 확인

  • 완료하면 홈의 30일 수락이 바로 올라가고, 내 성과에 완료 실적·평균 별점·후기가 쌓입니다.
  • 내가 추천인으로 지정된 업체·기사의 실적이 확인되면 소개 수수료가 적립 대기로 쌓이고, 관리자 지급 처리 후 지급 완료로 표시됩니다.
  • 내 정보(성명·전화·주소·서비스 지역 등) 변경이 필요하면 관리자(070-4995-3910)에게 문의하세요.
