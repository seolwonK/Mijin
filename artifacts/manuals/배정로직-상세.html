읽는 방법

먼저 들어가는 길을 따라 화면을 엽니다. 번호가 표시된 사진은 바로 아래 설명과 같은 위치를 가리킵니다. 입력·저장·상태 변경은 실제 처리할 대상과 내용을 확인한 뒤 진행합니다.

라이브 고객·업무 정보가 포함될 수 있으므로 내부 교육과 운영 목적으로 사용합니다. 계정의 비밀번호와 개인 인증 정보는 이 문서에 싣지 않습니다.

SECTION 01

배정이 이루어지는 세 경로

들어가는 길 접수 생성 · 응답 기한 만료 · 관리자 배정

사용 순서

  1. 고객이 새 접수를 제출하면 접수 지역을 판단하고 후보를 확인해 초기 자동배정을 시도합니다.
  2. 자동배정 워커는 배정 대기와 응답 기한이 지난 건을 다시 점검합니다.
  3. 관리자는 접수별 후보를 확인하고 수동으로 대상을 선택할 수 있습니다.

함께 확인하세요

  • 자동배정이 켜져 있고 주소에서 지역을 판별할 수 있을 때 초기 자동배정을 시도합니다. 지역 판별 불가·후보 없음은 관리자 확인이 필요한 상태로 남습니다.
  • 설정의 대기시간은 즉시 배정에 실패했거나 대기 중인 접수를 워커가 재검토하는 안전망 기준입니다. 현재 설정 화면의 값을 확인합니다.
SECTION 02

배정 후보의 자격과 담당 지역

들어가는 길 접수별 배정 후보

사용 순서

  1. 승인되고 활성인 업체와 기사가 기본 후보입니다. 기사는 근로확인서 서명 완료가 추가로 필요합니다.
  2. 접수 주소에서 시도·시군구를 판단하고 후보가 그 지역을 담당하는지 비교합니다.
  3. 좌표가 없으면 거리 미확인으로 표시됩니다. 주소에 의한 담당 지역·같은 시군구 판단과 좌표에 의한 거리 계산은 구분합니다.

함께 확인하세요

  • 실제 배정에서 담당 지역 미지정은 전 지역 담당으로 취급될 수 있지만, 분석 지도에서는 명시적 담당 등록 수만 셉니다. 두 화면의 인원을 같은 것으로 해석하면 안 됩니다.
  • 알이 0개인 것만으로 배정 후보에서 제외되거나 수락이 금지되지는 않습니다.
SECTION 03

일반·긴급 접수의 후보 비교 순서

들어가는 길 배정 후보 · 순환 현황

사용 순서

  1. 같은 접수에 거절·무응답 회수·관리자 회수 이력이 없는 후보를 먼저 비교합니다. 해당 이력이 있는 후보는 관리자 목록에서는 후순위이며 자동배정에서는 제외됩니다.
  2. 해당 접수 지역 담당 후보를 우선합니다.
  3. 그 안에서 알 보유량이 많은 순 → 최근 30일 수락·거절 응답 배정 횟수가 적은 순 → 평균 평점이 높은 순 → 거리가 가까운 순으로 비교합니다.
  4. 모두 같으면 안정적인 내부 키 순서를 사용해 결과를 일관되게 유지합니다.

함께 확인하세요

  • 순환 횟수는 알 보유량이 같을 때의 비교 기준입니다. 배정 횟수가 적다고 알이 더 많은 후보를 항상 앞서는 것은 아닙니다.
  • 후기가 없는 후보는 순위 계산에 기본값 3.0을 사용합니다. 이를 실제 고객 평점으로 표시하거나 설명하지 않습니다.
SECTION 04

초긴급은 같은 시군구와 거리 우선

들어가는 길 초긴급 접수의 배정 후보

사용 순서

  1. 거절·회수 이력과 담당 지역 비교를 먼저 적용합니다.
  2. 소재지 주소가 접수지와 같은 시군구인 후보를 우선합니다.
  3. 같은 시군구 여부가 같은 후보끼리는 알 보유량, 거리 순으로 비교합니다.
  4. 일반·긴급의 30일 응답 횟수와 평점 비교는 초긴급에 적용하지 않습니다.

함께 확인하세요

  • 접수지 또는 후보 소재지의 시군구를 명확히 판단할 수 없으면 같은 시군구라고 인정하지 않습니다.
  • 초긴급의 정확한 순위는 해당 접수 상세에서 확인합니다. 순환 현황은 일반·긴급 참고 순위입니다.
SECTION 05

알의 충전·수락 차감과 순위 영향

들어가는 길 포털 알 충전하기 · 관리자 알 크레딧

사용 순서

  1. 충전은 최소 30알, 30알 단위이며 1알 가격은 1,000원입니다.
  2. 업체·기사는 수량·금액·입금 계좌를 확인하고, 관리자가 입금 확인 후 충전합니다.
  3. 배정 수락 시 잔액이 있으면 1알 차감되고 변동 이력이 남습니다. 같은 배정을 반복 처리해 중복 차감하지 않도록 제어합니다.
  4. 충전이나 차감으로 알이 달라지면 같은 상위 조건 안에서 순위도 달라질 수 있습니다.

SECTION 06

10분 응답 기한과 재배정

들어가는 길 응답 대기 · 관리자 확인

사용 순서

  1. 배정 제안 후 10분 안에 수락 또는 거절을 확인합니다.
  2. 기한 내 응답이 없으면 약 30초 주기로 점검하는 워커가 해당 배정을 회수합니다. 자동배정이 켜져 있으면 다음 후보를 검토하고, 꺼져 있으면 관리자에게 반환합니다.
  3. 이미 거절하거나 회수된 대상이 같은 접수를 반복해서 받지 않도록 후순위로 비교합니다.
  4. 처리 가능한 후보가 없거나 자동으로 해결되지 않으면 관리자 확인이 필요한 상태를 확인합니다.

함께 확인하세요

  • 무응답 회수는 자동배정이 꺼져 있어도 작동하며, 수동배정 건에도 적용됩니다.
  • 워커 점검 주기 때문에 표시 시각과 실제 상태 반영 사이에 짧은 차이가 있을 수 있습니다.
  • 10분 응답 기한은 모든 긴급도에 공통이며 설정 화면의 대기시간과 별개입니다.
SECTION 07

관리자 판단과 예외 처리

들어가는 길 접수 상세

사용 순서

  1. 관리자는 추천 순위를 참고하되 현장·연락 결과를 확인한 뒤 수동 대상을 선택할 수 있습니다.
  2. 후보를 다시 지정할 때 기존 배정 이력과 회수 사유를 확인합니다.
  3. 배정 회수는 담당을 변경하는 절차, 접수 취소는 접수 자체를 종료하는 절차로 구분합니다.

함께 확인하세요

  • 수동 배정 확정은 실제 배정과 문자 안내를 발생시킬 수 있습니다. 운영 접수에서 단순 시연 목적으로 확정하지 않습니다.
SECTION 08

관리자와 포털의 조회 범위

들어가는 길 순환 현황 · 포털 내 알

사용 순서

  1. 관리자는 접수별 후보와 지역별 참고 순위에서 여러 업체·기사를 비교할 수 있습니다.
  2. 업체·기사는 자기 알 잔액과 자기에게 제공되는 순위·성과 정보를 확인합니다.
  3. 다른 업체의 비공개 정보나 전체 후보 명단이 포털에 공개되는 것으로 안내하지 않습니다.
SECTION 09

작업 금액과 소개 수수료의 근거

들어가는 길 설문 · 정산 집계 · 소개 수수료

사용 순서

  1. 작업 완료 후 고객이 설문에 평점과 선택 항목인 작업 금액을 입력합니다.
  2. 금액이 입력된 설문을 근거로 소개 수수료 3%가 계산됩니다. 동일 설문에 중복 적립되지 않도록 제어합니다.
  3. 관리자는 신고 원본과 실제 지급 근거를 확인한 뒤 수수료 지급 상태를 처리합니다.

함께 확인하세요

  • 고객이 금액을 입력하지 않으면 그 금액을 시스템이 자동 추정하지 않습니다.
  • 소개 수수료 적립과 실제 입금·송금의 확인은 구분합니다.
SECTION 10

운영 중 확인할 항목

들어가는 길 설정 · 접수 관리 · 순환 현황

사용 순서

  1. 자동배정 활성 여부, 담당 서비스 지역, 업체·기사의 활성·승인 상태를 확인합니다.
  2. 기사 근로확인서 서명 여부와 현장 좌표·주소의 정확성을 확인합니다.
  3. 문자 발송 설정·잔액과 관리자 알림 수신처를 점검합니다. 화면에 보이는 발송 요청 완료를 최종 수신 보장으로 해석하지 않습니다.
  4. 원인이 불명확하면 접수별 상태·배정 이력·알 변동 이력을 같은 시점 기준으로 대조합니다.

함께 확인하세요

  • 문자 장애가 있어도 접수·배정 상태는 따로 저장될 수 있습니다. 포털과 고객 접수조회를 확인하고 필요한 경우 전화로 안내합니다.
