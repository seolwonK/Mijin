읽는 방법

먼저 들어가는 길을 따라 화면을 엽니다. 번호가 표시된 사진은 바로 아래 설명과 같은 위치를 가리킵니다. 입력·저장·상태 변경은 실제 처리할 대상과 내용을 확인한 뒤 진행합니다.

라이브 고객·업무 정보가 포함될 수 있으므로 내부 교육과 운영 목적으로 사용합니다. 계정의 비밀번호와 개인 인증 정보는 이 문서에 싣지 않습니다.

따라하기 01

업체 포털에 들어가기

들어가는 길 /partner/login

  1. 메인 화면 하단의 업체·기사 로그인에서 해당 포털을 선택합니다. 가입할 때 만든 아이디와 비밀번호로 로그인합니다.
  2. 처음 이용한다면 가입 신청으로 이동합니다. 입력 오류가 있으면 해당 칸의 안내를 확인합니다.
  3. 포털 상단의 내 정보와 로그아웃 위치를 확인합니다.

함께 확인하세요

  • 업체는 가입 신청 후 관리자 승인이 필요합니다. 승인 대기·거절 안내를 확인하고, 거절 사유가 있으면 관리자에게 보완 방법을 문의합니다.
따라하기 02

가입: 계정과 기본 정보

들어가는 길 /partner/signup

  1. 3~30자 아이디를 정하고 중복 확인을 누릅니다. 8자 이상 비밀번호와 비밀번호 확인을 입력합니다.
  2. 업체명과 연락처, 주소를 입력합니다. 실제 배정 연락을 받을 번호를 사용합니다.
  3. 주소의 시도·시군구와 상세 주소를 확인합니다. 서비스 가능 지역에서 담당할 지역을 추가하거나 잘못 넣은 지역을 삭제합니다.
  4. 추천인이 있다면 가입 시점에 전화번호로 확인하고 지정합니다. 약관·개인정보 동의 내용을 확인합니다.

함께 확인하세요

  • 아이디 또는 추천인 확인 후 입력값을 바꾸었다면 다시 확인합니다. 서버 오류 안내를 중복 가능 또는 확인 완료로 해석하지 않습니다.
  • 추천인은 가입 시 지정하므로 신청 전 대상을 확인합니다.
  • 시도만 선택하면 해당 시도 전체를 담당합니다. 서비스 지역을 모두 비우면 전 지역으로 취급되므로 실제 담당할 지역을 지정합니다.
따라하기 03

사업자 증빙과 가입 신청

들어가는 길 /partner/signup

  1. 10자리 사업자등록번호를 입력하고 사업자등록증·전기공사업 등록증 2종을 첨부합니다. 각 파일은 최대 8MB이며 JPG·PNG·WEBP·HEIC·PDF를 사용할 수 있습니다.
  2. 첨부된 파일 이름과 서비스 지역, 연락처, 동의를 확인한 뒤 가입 신청하기를 누릅니다.
  3. 신청 완료 안내를 확인합니다. 관리자 승인 후 업체 포털에 로그인할 수 있습니다.

함께 확인하세요

  • 업체 승인과 전기기사의 가입 완료 절차는 다릅니다. 기사의 즉시 승인 안내를 업체에 적용하지 않습니다.
따라하기 04

홈의 운영 현황 읽기

들어가는 길 /partner

  1. 맨 위에서 내 알과 소개 수수료 누적 적립액을 확인합니다. 알 충전하기와 소개 수수료 상세로 바로 이동할 수 있습니다.
  2. 응답 대기·진행 중·30일 배정 수치를 확인합니다. 30일 수락과 평균 별점·후기 수도 함께 읽습니다.
  3. 응답 대기에는 수락 여부를 결정할 작업, 진행 중에는 수락·출동 단계의 작업이 표시됩니다.
  4. 지난 내역의 전체 보기로 이전 작업을 확인합니다. 새 데이터가 필요하면 전체 새로고침을 누릅니다.

함께 확인하세요

  • 홈의 소개 수수료는 지급 대기와 지급 완료를 합친 전체 기간 누적 적립액입니다. 지급 상태별 원본은 소개 수수료 화면에서 확인합니다.
  • 배정 중지·미승인·기사 미서명 상태라면 배정 노출 순위 대신 해당 상태가 안내됩니다. 순위가 비어 있다고 잔액 소멸을 뜻하지는 않습니다.
  • 잔액·집계가 —로 보이면 불러오는 중이거나 조회 오류인지 확인합니다. 0과 미조회는 다릅니다.
따라하기 05

새 배정 알림과 응답 시간

들어가는 길 /partner

  1. 새 배정 브라우저 알림 켜기를 눌러 알림을 허용합니다. 브라우저가 차단했다면 해당 사이트 알림 설정을 확인합니다.
  2. 일하는 동안 포털을 열어 두고 새 배정과 남은 응답 시간을 확인합니다.
  3. 새 배정이 보이면 상세를 열어 수락 또는 거절을 결정합니다.

함께 확인하세요

  • 배정 후 응답 제한은 10분입니다. 시간이 지나면 관리 시스템에서 회수하고 다음 대상으로 넘어갈 수 있습니다.
  • 알림음·진동·탭 제목 알림은 포털을 열어 둔 환경과 브라우저 권한의 영향을 받습니다. 화면을 닫아도 항상 도착하는 푸시 알림으로 가정하지 않습니다.
따라하기 06

배정 상세 확인과 수락

들어가는 길 /partner/jobs/…

  1. 응답 대기 작업을 눌러 고장 내용·사진·긴급도·위치와 남은 응답 시간을 확인합니다. 사진을 누르면 확대되며 방향키로 넘기고 닫기 또는 Escape로 닫을 수 있습니다.
  2. 지도·길찾기와 전화 버튼을 통해 현장과 고객 연락 정보를 확인합니다.
  3. 실제로 처리할 수 있으면 수락을 누릅니다. 진행 중으로 이동하고 상태가 바뀌었는지 확인합니다.

함께 확인하세요

  • 수락 시 알이 1개 이상 있으면 1알 차감됩니다. 잔액 0알이면 차감 없이 수락할 수 있습니다.
  • 상태 조회가 실패하면 마지막 연락처·주소는 남아도 처리 버튼은 잠깁니다. 다시 시도로 최신 상태를 확인한 뒤 진행합니다. 사진 오류도 사진창의 다시 시도를 이용합니다.
  • 상태가 바뀌었거나 회수된 건은 새로고침 후 확인합니다. 이미 처리된 작업에서 버튼을 반복해서 누르지 않습니다.
따라하기 07

출동 시작·작업 완료·거절

들어가는 길 /partner/jobs/…

  1. 수락한 작업은 실제 이동을 시작할 때 출동 시작을 누르고 확인창의 내용을 확인한 뒤 확정합니다.
  2. 수리가 끝나면 작업 완료를 누르고 확인창에서 확정합니다. 완료된 건은 지난 내역에서 확인합니다.
  3. 배정을 맡을 수 없다면 응답 대기 단계에서 거절을 누릅니다. 거절 사유는 선택 항목이며 200자까지 입력할 수 있습니다. 거절 결과를 확인합니다.

함께 확인하세요

  • 완료하면 고객 만족도 설문 안내가 발송될 수 있습니다.
  • 거절 후 즉시 재배정은 자동배정 건에 거리 확인이 가능한 다음 후보가 있을 때만 이루어집니다. 수동배정 건이나 후보가 없는 건은 관리자에게 반환됩니다.
  • 수락 후 업무 변경이 필요하면 관리자에게 연락합니다. 응답 대기의 거절과 관리자의 배정 회수는 다른 절차입니다.
따라하기 08

지난 내역 검색과 상태 확인

들어가는 길 /partner/history

  1. 홈의 지난 내역 전체 보기 또는 30일 배정을 눌러 내역 화면으로 이동합니다.
  2. 주소·고장 내용·고객명 검색에 검색어를 입력하고 검색을 누릅니다. 배정 상태에서 전체 상태·작업 완료·거절한 배정·응답 기한 만료·배정 취소를 선택합니다.
  3. 총 건수와 현재 페이지를 확인하고 20건씩 이전 페이지·다음 페이지로 이동합니다. 결과가 없으면 검색어와 상태를 바꿉니다.
  4. 접수 내용과 작업 결과를 확인하고 필요한 경우 상세를 엽니다.

함께 확인하세요

  • 완료·거절·회수 등 서로 다른 결과를 구분합니다. 내역의 누적 범위와 홈의 최근 30일 지표는 같지 않을 수 있습니다.
따라하기 09

알 충전하기와 입금 안내

들어가는 길 /partner/eggs/charge

  1. 홈의 내 알에서 알 충전하기를 누릅니다.
  2. 1판·2판·3판 버튼 또는 수량 입력으로 충전할 알을 고릅니다. 최소 30알이며 30알 단위입니다.
  3. 입금 금액을 확인합니다. 알 1개는 1,000원이므로 30알은 30,000원입니다.
  4. 등록된 은행·계좌번호·예금주와 입금자명을 확인하고 실제 입금을 진행합니다. 계좌번호 복사를 사용할 수 있습니다.
  5. 관리자가 입금을 확인한 뒤 알을 충전합니다. 확인이 늦거나 입금자명이 다르면 충전 문의로 연락합니다.

함께 확인하세요

  • 계좌 준비 중이면 아직 입금 계좌가 등록되지 않은 상태입니다. 임의의 계좌로 송금하지 말고 관리자에게 문의합니다.
  • 수량을 선택하는 것만으로 충전 신청·자동 결제가 완료되는 것은 아닙니다. 잔액은 관리자 충전 처리 후 확인합니다.
따라하기 10

소개 수수료와 추천 현황

들어가는 길 /partner/commissions

  1. 홈의 소개 수수료 누적 금액을 눌러 상세 내역으로 이동합니다.
  2. 지급 대기·지급 완료 상태와 적립 날짜·해당 작업의 금액을 확인합니다. 홈에는 최근 3건이 나오고, 전체 내역은 50건씩 이전 페이지·다음 페이지로 이동합니다.
  3. 홈의 내 추천 현황에서 소개한 업체·기사의 상태와 설문 응답을 확인합니다.

함께 확인하세요

  • 소개 수수료는 소개받은 업체·기사의 작업에 대해 고객이 설문에 입력한 작업 금액을 근거로 3%가 적립됩니다. 시스템이 실제 은행 입금을 자동 조회하지는 않습니다.
  • 고객이 금액을 입력하지 않았거나 설문이 아직 제출되지 않았다면 해당 금액을 확인할 수 없습니다.
따라하기 11

평점·후기와 서비스 개선

들어가는 길 /partner

  1. 받은 후기에서 평균 별점과 점수 분포, 후기 수를 확인합니다.
  2. 코멘트가 공개되면 고객 의견을 읽고 반복되는 불편을 정리합니다.
  3. 표시된 공개 기준이나 조회 오류 안내를 확인합니다.

함께 확인하세요

  • 후기가 5건 미만이면 코멘트는 공개되지 않습니다. 평균·분포와 코멘트 공개는 구분합니다.
따라하기 12

내 정보와 새 배정 받기 설정

들어가는 길 /partner/profile

  1. 포털 상단의 내 정보를 엽니다. 이름·아이디·승인 상태 등 기본 정보를 확인합니다.
  2. 배정 연락처·주소·서비스 가능 지역을 수정합니다. 수정한 내용은 저장해야 반영됩니다.
  3. 쉬는 날이나 배정을 받을 수 없는 때에는 새 배정 받기를 꺼짐 · 배정 중지로 바꾸고 저장하기를 누릅니다. 다시 받을 때는 켜짐 · 배정 받기로 저장합니다.
  4. 저장되었습니다. 배정 설정에 적용했습니다. 안내와 다시 조회한 값을 확인합니다. 신원 정보 변경이나 승인 관련 문의는 관리자에게 연락합니다.

함께 확인하세요

  • 편집 중 페이지를 나가면 저장하지 않은 값이 사라질 수 있습니다. 저장 여부를 확인합니다.
  • 휴무·비활성 전환은 이미 수락한 작업을 자동 취소하는 기능이 아닙니다. 진행 중인 작업은 별도로 관리자와 조율합니다.
