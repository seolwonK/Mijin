작업 1가입 신청하기

들어가는 길: 전기아저씨.com → 업체 포털 → 가입 신청
로그인 아이디(3자 이상)를 입력하고 중복 확인을 누릅니다 — "사용할 수 있는 아이디입니다" 초록 문구가 나오면 통과
비밀번호(8자 이상)와 확인을 입력하고, 아래로 내려 업체명(사업자등록증 상호와 동일하게)·전화번호·주소를 입력합니다
서비스 가능 지역에서 시/도(·시/군/구)를 고르고 추가를 누릅니다. 여러 지역 반복 추가 가능 — 등록한 지역의 접수만 배정됩니다
사업자등록번호를 입력하고 사업자등록증 사진 첨부를 누릅니다 — 검증번호까지 확인하므로 실제 발급받은 번호여야 합니다
전기공사업 등록증 사진 첨부도 누릅니다 — 두 증빙 모두 있어야 신청됩니다 (JPG/PNG/PDF, 8MB 이하, 글자 선명하게)
약관·개인정보 동의 체크 후
가입 신청하기를 누릅니다
승인 대기 안내가 나오면 신청 완료. 관리자 승인 후부터 로그인할 수 있습니다.
추천인이 있다면 신청서의 추천인 칸에 전화번호로 조회한 뒤, 가려진 이름(예: 김○수) 목록에서 고릅니다 — 가입 때만 넣을 수 있고 승인·활성 회원만 조회됩니다.

작업 2로그인하기

들어가는 길: 전기아저씨.com → 업체 포털
아이디 입력
비밀번호 입력
로그인 누르기
업체 포털 홈(30일 수락·내 알 카드가 보이는 화면)이 열리면 성공.
"아이디 또는 비밀번호가 올바르지 않습니다"가 나오면 대소문자를 확인하세요. 승인 전 계정은 "가입 승인 대기 중입니다"로 막히고, 거절된 계정은 거절 사유가 함께 표시됩니다.
로그아웃할 때는 홈 오른쪽 위 내 정보 옆 로그아웃을 누릅니다. 공용 PC에서는 반드시 눌러 주세요.
로그인 상태는 7일 유지됩니다. 저절로 풀리면 로그인 화면에 "로그인이 필요합니다" 배너가 뜨고, 다시 로그인하면 보던 화면으로 돌아옵니다.

작업 3홈 화면 한눈에 보기

들어가는 길: 로그인 직후 첫 화면
맨 위 요약: 30일 수락 건수 · 소개 수수료 적립 대기 · 지급 완료 금액
응답 대기: 수락/거절을 기다리는 배정 카드들 — 여기 있는 건부터 처리하세요 (작업 5)

아래로 내리면 진행 중(수락~완료 전) → 내 성과(30일 배정·수락·별점·후기) → 소개 수수료 → 지난 내역(20건, 전체 보기 있음) → 내 추천 현황 → 받은 후기 순서로 이어집니다.

소개 수수료는 적립 이력이 하나도 없으면 아예 보이지 않습니다. 내 추천 현황과 받은 후기는 작업 13에서 봅니다.

작업 4새 배정 알림 켜기

들어가는 길: 홈 → 요약 카드 아래
새 배정 브라우저 알림 켜기를 누릅니다
브라우저 권한 창에서 허용을 선택합니다
권한을 허용하면 버튼이 사라집니다. 포털 탭을 열어 둔 동안 새 배정이 오면 알림음·진동이 울리고 탭 제목이 (1) 업체 포털로 바뀝니다.
포털을 닫아 두면 알림이 오지 않습니다. 새 배정 확인은 화면이 열려 있는 동안에만 이루어집니다. 다른 앱으로 넘어가거나 휴대폰 화면을 끄면 확인이 멈춥니다. 배정 후 10분 안에 응답이 없으면 자동으로 다음 업체에게 넘어가므로, 근무 중에는 포털 탭을 항상 열어 두세요.

작업 5배정 확인하고 수락하기

들어가는 길: 홈 → 응답 대기 카드 (또는 알림 클릭)
배정되면 고객 이름·전화번호·주소·거리가 담긴 안내 문자가 옵니다. 고객 개인정보이니 다른 곳에 옮기지 마시고 출동 후에는 지워 주세요.
응답 대기의 배정 카드를 누릅니다 (긴급도·고장 내용·주소·배정 시각이 미리 보입니다)
상세에서 확인: 경과 배너 → 고장 내용 → 고객 첨부 사진(누르면 크게) → 위치(지도 보기·길찾기) → 고객(전화 버튼). 버튼 위 안내(①번 박스): "수락하면 알 1개가 차감됩니다 (잔액이 없으면 차감 없이 수락)"
경과 배너의 1시간·2시간은 고객에게 도착하기까지의 목표입니다. 수락·거절 응답 시한은 긴급도와 상관없이 10분입니다. 좌표가 없는 건은 거리가 아예 표시되지 않습니다.
출동 가능하면 수락하기 — 확인창 없이 즉시 수락됩니다
어려우면 거절 (작업 8)
상태 배지가 수락됨으로 바뀌고 버튼이 출동 시작으로 바뀌면 성공.

작업 6출동 시작하기

들어가는 길: 수락한 배정 상세 (홈 → 진행 중 카드)
현장으로 출발할 때 출동 시작을 누릅니다
확인창 "출동을 시작할까요?"에서 출동 시작을 누릅니다
상태 배지가 출동중으로 바뀝니다. 길찾기 버튼으로 내비를 바로 열 수 있습니다.

작업 7완료 처리하기

들어가는 길: 출동중 배정 상세
현장 작업이 끝나면 완료 처리를 누릅니다
확인창 "완료 처리할까요? 되돌릴 수 없습니다."를 읽고
완료 확정을 누릅니다
처리가 끝나고, 이 건은 홈의 지난 내역으로 이동합니다 (아래 그림). 이후 고객에게 만족도 조사가 가고 별점·후기가 내 평점에 쌓입니다.
완료는 되돌릴 수 없습니다. 반드시 실제 작업이 끝난 뒤에 누르세요. 수리 대금은 현장에서 고객과 직접 정산합니다.

작업 8배정 거절하기

들어가는 길: 응답 대기 배정 상세 (작업 5의 ②번 버튼)
상세 화면에서 거절을 누릅니다 (작업 5 세 번째 그림의 ②번 박스)
사유 입력란은 "거절 사유 (선택)"입니다 — 비워 두어도 거절됩니다(200자까지). 적으면 관리자 화면의 배정 이력에 남습니다
거절 확정을 누릅니다
카드가 응답 대기 목록에서 사라지면 처리 완료. 거절해도 알은 차감되지 않습니다.
거절한 접수가 항상 곧바로 다음 업체에게 가지는 않습니다. 자동으로 배정된 건이면서 거리 확인이 되는 다음 후보가 있을 때만 즉시 넘어가고, 관리자가 직접 배정한 건이거나 접수에 좌표가 없으면 배정 대기로 돌아가 관리자가 다시 판단합니다.
거절이 잦으면 배정 추천 순위에서 불리해집니다. 받을 수 없는 지역·시간대라면 서비스 지역(작업 11)이나 영업 상태(작업 12)를 미리 조정하는 것이 좋습니다.

작업 9내 알·노출 순위 확인하기

들어가는 길: 홈 → 내 알 카드
내 알: 현재 보유 알 — 배정을 수락할 때마다 1알 차감 (0알이어도 수락은 되고 차감만 없음)
배정 노출 순위: 같은 지역 업체 중 내가 몇 번째로 배정 제안을 받는지 (알이 많을수록 우선)
충전이 필요하면 관리자(070-4995-3910)에게 요청 — 최소 3알, 1알 = 1,000원. 입금 확인 후 바로 잔액에 반영됩니다.

작업 10소개 수수료 확인하기

들어가는 길: 홈 → 아래로 스크롤 → 소개 수수료
소개 수수료 구역에서 대기(적립됐지만 미지급)와 지급 완료 금액, 최근 내역 소계(최대 50건)와 건별 내역(5건 + 전체 보기)을 확인합니다
대기·지급 완료 금액과 건별 내역이 보이면 성공.
내가 추천인으로 지정된 업체·기사가 작업을 완료하고, 그 건의 고객이 만족도 조사를 제출하면서 지불 금액을 입력하면 그 금액의 2%(원 단위 내림)가 적립됩니다. 관리자가 지급 처리하면 지급 완료로 넘어갑니다.
고객이 조사에서 금액을 비우면 수수료가 적립되지 않습니다. 적립 이력이 하나도 없으면 이 구역 자체가 홈에 나타나지 않습니다.

화면 맨 아래 저장하기를 눌러야 반영됩니다.

작업 13내 추천 현황·받은 후기 보기

들어가는 길: 홈 → 맨 아래까지 스크롤
내 추천 현황: 내가 추천인으로 지정된 인원과 설문 대기 건수, 대상별 이름·유형·승인 상태·가입일·적립 대기·지급 완료를 확인합니다
받은 후기: 평균 별점·후기 건수와 1~5점 분포 막대를 확인합니다
추천 인원과 별점 분포가 보이면 성공. 추천한 사람이 없으면 "아직 추천한 업체·전기기사가 없습니다"가 표시됩니다.
후기에 적힌 글은 후기가 5건 이상 모여야 보입니다. 그 전에는 "후기가 5건 이상 모이면 코멘트를 확인할 수 있어요" 안내만 나옵니다. 추천인은 상대방이 가입할 때만 지정할 수 있습니다.
