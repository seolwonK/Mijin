접속
전기아저씨.com

3.0 · 2026-09-10 라이브 화면

새 메뉴와 화면 배치를 기준으로 본문과 스크린샷을 다시 작성했습니다. 숫자와 목록은 촬영 시점의 예시이며 실제 이용 시 달라질 수 있습니다.

목차

  1. 홈에서 접수 시작하기
  2. 고장 내용·음성·사진 입력
  3. 긴급도·주소·연락처 확인
  4. 접수 완료와 접수번호 보관
  5. 내 접수 진행 상황 조회
  6. 만족도 설문과 실제 지불 금액

읽는 방법

먼저 들어가는 길을 따라 화면을 엽니다. 번호가 표시된 사진은 바로 아래 설명과 같은 위치를 가리킵니다. 입력·저장·상태 변경은 실제 처리할 대상과 내용을 확인한 뒤 진행합니다.

라이브 고객·업무 정보가 포함될 수 있으므로 내부 교육과 운영 목적으로 사용합니다. 계정의 비밀번호와 개인 인증 정보는 이 문서에 싣지 않습니다.

따라하기 01

홈에서 접수 시작하기

들어가는 길 /

  1. 휴대폰 브라우저에서 전기아저씨.com에 접속합니다.
  2. 하단 고장 접수하기 또는 해당 증상을 눌러 접수 화면으로 이동합니다. 증상을 누르면 설명이 미리 입력되며 긴급도는 직접 선택합니다.
  3. 이미 접수한 건은 접수조회에서 확인합니다. 업체·기사 로그인은 작업자 포털 입구입니다.
따라하기 02

고장 내용·음성·사진 입력

들어가는 길 /request/new

  1. 어떤 문제가 생겼는지 구체적으로 입력합니다. 고장 난 위치, 차단기 상태, 언제부터 발생했는지 적으면 도움이 됩니다.
  2. 음성으로 입력하기가 표시되는 브라우저에서는 마이크 권한을 허용하고 녹음합니다. 3분이 되면 자동 종료됩니다. 미리듣기로 확인하고 잘못 녹음했으면 삭제하거나 다시 녹음합니다.
  3. 사진 촬영 또는 앨범에서 선택으로 고장 사진을 넣습니다. 잘못 고른 사진은 삭제합니다.

함께 확인하세요

  • 사진은 최대 5장, 한 장 10MB까지 JPG·PNG·WEBP 형식으로 첨부할 수 있습니다. 사진은 접수 전에 확인하세요. 고객 조회 화면에서는 제출한 사진을 다시 열 수 없습니다.
  • 아이폰의 음성 입력은 Safari를 이용합니다. 버튼이 없거나 권한을 사용할 수 없으면 글로 입력합니다. 텍스트 없이 음성만 첨부해도 접수할 수 있으며, 텍스트 변환은 브라우저와 서버 설정에 따라 달라집니다.
  • 작성 중 새로고침하면 텍스트 입력 일부가 복원될 수 있지만 음성·사진 첨부는 다시 확인합니다. 새 녹음은 기존 녹음을 대체합니다.
따라하기 03

긴급도·주소·연락처 확인

들어가는 길 /request/new

  1. 얼마나 급한가요?에서 현장 상황에 맞는 긴급도를 선택합니다.
  2. 내 위치로 채우기, 주소 검색 또는 직접 입력으로 주소를 넣습니다. 동·호수 등 상세 주소도 확인합니다.
  3. 이름과 전화번호를 입력합니다. 이 번호로 진행 상황을 조회하고 담당자의 연락을 받습니다.
  4. 개인정보 동의와 입력 내용을 확인한 뒤 접수하기를 누릅니다. 빠진 항목이 있으면 오류가 표시된 입력 칸으로 이동하므로 수정한 뒤 다시 제출합니다.

함께 확인하세요

  • 위치 권한을 허용하지 않아도 주소를 직접 입력할 수 있습니다.
  • 긴급도는 접수 우선순위를 위한 선택입니다. 화면의 안내를 확인하고, 감전·화재 등 즉각적인 위험이 있는 상황에서는 현장 안전을 우선합니다.
따라하기 04

접수 완료와 접수번호 보관

들어가는 길 접수하기 → 완료 화면

  1. 접수가 완료되었습니다 안내와 접수번호를 확인합니다.
  2. 접수번호 복사로 번호를 보관하고 진행 상황 조회하기로 이동합니다.
  3. 잘못 입력했거나 취소가 필요하면 문의 전화로 연락합니다.

함께 확인하세요

  • 문자가 오지 않더라도 접수가 완료되었을 수 있습니다. 반복 제출하기 전에 접수조회로 확인합니다.
  • 문자 발송·수신 상태와 접수 저장 성공 여부는 별개입니다.
따라하기 05

내 접수 진행 상황 조회

들어가는 길 /lookup

  1. 메인 화면에서 접수조회를 누릅니다.
  2. 접수할 때 입력한 전화번호로 조회합니다.
  3. 접수 상태와 고장 내용, 배정된 담당자 정보를 확인합니다. 새 정보가 필요하면 새로고침합니다.
  4. 완료 후 설문 참여가 표시되면 해당 링크를 엽니다.

함께 확인하세요

  • 같은 전화번호의 최신 접수 20건까지 표시됩니다. 여러 건이면 접수번호·일시·내용으로 구분합니다. 열린 화면은 15초마다 자동 갱신됩니다.
  • 담당자 정보는 수락 전 응답 대기 단계부터 표시될 수 있습니다. 실제 수락·출동 상태를 함께 확인합니다.
  • 고객 문자 안내는 접수 완료와 작업 완료 후 설문 안내입니다. 배정·수락·출동·취소 문자가 각각 오는 방식은 아니므로 접수조회에서 상태를 확인합니다.
따라하기 06

만족도 설문과 실제 지불 금액

들어가는 길 문자의 설문 링크 또는 접수조회 → 설문 참여

  1. 작업 완료 후 받은 설문 링크를 엽니다. 문자 대신 접수조회에 표시되는 설문 참여 경로를 이용할 수도 있습니다.
  2. 필수 항목인 평점을 선택합니다. 후기는 선택 항목이며 500자까지 입력할 수 있습니다.
  3. 지불 금액은 선택 항목입니다. 입력한다면 실제로 지불한 작업 금액을 0원~1억원 범위로 적습니다. 0원과 미입력은 다르게 집계됩니다.
  4. 내용을 확인하고 제출합니다. 제출 완료 안내가 나오면 종료합니다.

함께 확인하세요

  • 이미 제출한 링크는 완료 안내를 보여줍니다. 잘못된 링크나 접수 정보가 나오면 관리자에게 문의합니다.
  • 설문 금액은 고객이 신고한 금액으로 집계됩니다. 실제 은행 입금을 자동 확인하는 과정이 아닙니다.
