기사 따라하기

화면 그대로 따라하는 전기기사 포털 플로우 매뉴얼 — 빨간 박스 번호 순서대로 누르면 됩니다
대상: 전기기사따라하기 별책 v1.12026-09-07
접속 주소: 전기아저씨.com → 기사 포털 (휴대폰 화면 기준)
문의 전화: 070-4995-3910
모든 화면의 빨간 박스와 번호가 누르거나 입력할 위치입니다.

작업 목차

  1. 가입 신청하기 휴대폰 본인인증 포함 — 끝나면 바로 로그인됩니다
  2. 로그인하기 다음 접속부터 쓰는 방법
  3. 근로확인서 서명하기 서명해야 배정을 받습니다 — 가입한 날 바로!
  4. 홈 화면 한눈에 보기
  5. 배정 확인하고 수락하기 10분 안에!
  6. 출동·완료 처리하기
  7. 내 성과 확인하기
  8. 내 알·노출 순위 확인하기
  9. 배정 거절하기
  10. 근로확인서 다시 보기

작업 1가입 신청하기

들어가는 길: 전기아저씨.com → 기사 포털 → 가입 신청
로그인 아이디(3자 이상)를 입력하고 중복 확인 — 초록 문구가 나오면 통과. 이어서 비밀번호(8자 이상)와 확인 입력
근로 형태를 고릅니다 — 일일 근로자(하루 8시간 단위) 또는 상시 근로자(평일 09~18시). 가입 후 근로확인서 기본값으로 이어집니다
성명·전화번호를 본인 명의 그대로 입력하고 본인인증을 누릅니다 — 인증 창에서 통신사를 고르고 문자로 받은 번호를 입력해 완료합니다. 인증을 마쳐야 가입할 수 있습니다
휴대폰으로 하는 경우 화면 전체가 인증 페이지로 넘어갔다가 가입 화면으로 돌아옵니다. 적어 둔 내용은 그대로 복원되지만 비밀번호만 다시 입력하면 됩니다
인증이 끝나면 성명·전화번호가 인증된 값으로 채워지고 수정할 수 없게 됩니다. 바꾸려면 옆의 변경을 누릅니다
인증 후 10분 안에 가입 신청까지 마쳐야 합니다. 넘기면 "본인인증 유효시간이 지났습니다"가 나오고 다시 인증해야 합니다.
주소를 채웁니다 — 거주 시/도를 고르면 서비스 가능 지역에 그 시/도가 자동으로 한 건 추가됩니다(필요 없으면 칩의 ×로 빼세요)
서비스 가능 지역을 더 넣고 약관·개인정보 동의 체크
가입 신청하기를 누릅니다
"가입이 완료되었습니다 / 자동으로 로그인되었습니다"가 나오면 끝 — 관리자 승인을 기다릴 필요 없이 이미 로그인된 상태입니다. 이어서 근로확인서 작성하러 가기를 누르면 바로 작업 3으로 갑니다.
PC에서 팝업이 차단돼도 같은 탭이 인증 화면으로 바뀌어 그대로 진행되므로 차단을 풀 필요는 없습니다. 추천인은 가입 때만 지정할 수 있습니다. 방금 만든 아이디·비밀번호는 다음 접속(작업 2)부터 필요하니 기록해 두세요.

작업 2로그인하기 (다음 접속부터)

들어가는 길: 전기아저씨.com → 기사 포털
가입 직후에는 이 작업이 필요 없습니다. 가입하면 자동으로 로그인되기 때문입니다. 나중에 다시 접속하거나 로그아웃한 뒤에 이 방법으로 들어옵니다.
아이디 입력 — 가입할 때 만든 아이디입니다
비밀번호 입력
로그인 누르기
기사 포털 홈이 열리면 성공. 근로확인서 서명을 아직 안 했다면 곧바로 작업 3으로 가세요.

작업 3근로확인서 서명하기

들어가는 길: 가입 완료 화면의 근로확인서 작성하러 가기 또는 홈 위쪽 노란 배너
서명을 완료하기 전에는 배정을 받을 수 없습니다. 가입한 날 바로 처리하세요.
홈의 "근로확인서 작성 필요" 배너를 누릅니다
확인 내용(근로개시일·근무장소·업무 내용)을 확인합니다 — 실제와 다르면 직접 고칠 수 있습니다. 아래 근로자 정보(성명·주소)와 임금(기본값)도 확인하세요 — 실제 조건은 이후 관리자가 조정합니다
근로자 서명 칸에 손가락(또는 마우스)으로 누른 채 끌어서 서명합니다 — 클릭만 하면 그려지지 않아요
잘못 그렸으면 지우기 후 다시
"서명됨" 표시를 확인하고 서명하고 완료를 누릅니다
홈 배너가 "근로확인서 서명 완료"(초록)로 바뀌면 끝 — 이제 배정을 받을 수 있습니다.
서명 후에는 확인서가 읽기 전용이 됩니다. 내용 수정은 관리자에게 문의하세요.

작업 4홈 화면 한눈에 보기

들어가는 길: 로그인 직후 첫 화면
맨 위 요약: 30일 수락 · 소개 수수료 적립 대기·지급 완료. 그 아래 내 알 카드, 근로확인서 배너, 응답 대기 → 진행 중 → 내 성과 → 내 추천 현황 → 받은 후기 순서로 이어집니다
맨 위 n초 전 확인은 마지막으로 정보를 불러온 시점입니다. 옆의 새로고침 버튼으로 즉시 다시 불러올 수 있습니다
받은 후기에는 평균 별점과 1~5점 분포가 나옵니다. 코멘트는 후기가 5건 이상 모여야 보입니다
일하는 동안에는 기사 포털 탭을 열어 두세요. 배정 후 10분 안에 응답하지 않으면 자동으로 다음 사람에게 넘어갑니다. 탭을 닫거나 화면을 끄면 새 배정을 확인하지 못하고, 브라우저 알림도 오지 않습니다.
포털 탭을 열어 둔 동안 새 배정이 오면 알림음·진동이 울리고 탭 제목에 (1)처럼 대기 건수가 표시됩니다. 새 배정 브라우저 알림 켜기도 눌러 허용해 두면 도움이 됩니다.

작업 5배정 확인하고 수락하기

들어가는 길: 홈 → 응답 대기 카드 (또는 알림 클릭)
응답 대기의 배정 카드를 누릅니다
상세 확인: 고장 내용 → 고객 사진(누르면 크게) → 위치(지도·길찾기) → 고객 전화. 버튼 위 안내(①): "수락하면 알 1개가 차감됩니다 (잔액이 없으면 차감 없이 수락)" — 알이 0개여도 수락은 됩니다
출동 가능하면 수락하기 — 즉시 수락됩니다
어려우면 거절 (작업 9)
상태가 수락됨으로 바뀌고 버튼이 출동 시작이 되면 성공.

작업 6출동·완료 처리하기

들어가는 길: 수락한 배정 상세 (홈 → 진행 중)
출발할 때 출동 시작 → 확인창에서 다시 출동 시작
작업이 끝나면 완료 처리
확인창 "완료 처리할까요? 되돌릴 수 없습니다."를 읽고
완료 확정
이 건이 지난 내역으로 이동하면 끝. 고객 만족도 조사의 별점·후기가 내 평점에 쌓입니다.
완료는 되돌릴 수 없습니다. 수리 대금은 현장에서 고객과 직접 정산합니다.

작업 7내 성과 확인하기

들어가는 길: 홈 → 아래로 스크롤 → 내 성과
내 성과: 30일 배정·수락 건수, 평균 별점, 후기 수 — 완료할 때마다 갱신됩니다. 별점은 배정 순위 산정에도 쓰입니다

작업 8내 알·노출 순위 확인하기

들어가는 길: 홈 → 내 알 카드
내 알: 수락할 때마다 1알 차감(0알이면 무차감 수락)
배정 노출 순위: 같은 지역 기사 중 내 순번 — 알이 많을수록 우선
충전은 관리자에게 문의(070-4995-3910) — 최소 3알, 1알 = 1,000원.

작업 9배정 거절하기

들어가는 길: 응답 대기 배정 상세 (작업 5의 ②번 버튼)
상세에서 거절을 누릅니다
사유를 남기고 거절 확정 — 사유는 선택 입력(200자)이라 비워 두고 눌러도 됩니다. 적으면 관리자 화면 이력에 남습니다
카드가 목록에서 사라지면 처리 완료.
거절한 접수가 항상 곧바로 다음 사람에게 가지는 않습니다. 자동 배정된 건이면서 위치가 확인된 다음 후보가 있을 때만 즉시 넘어가고, 관리자가 직접 배정한 건이거나 접수에 위치 정보가 없으면 배정 대기로 돌아가 관리자가 판단합니다. 거절이 잦으면 배정 순위에서 불리해집니다. 알 차감은 없습니다(차감은 수락 시에만).
