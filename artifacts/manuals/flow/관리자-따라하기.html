모든 화면의 빨간 박스와 번호가 클릭·입력 위치입니다. 일부 화면은 7월 주석본을 사용하며 현행 화면과 배색이 조금 다를 수 있습니다(위치·기능 동일).
즉시 반영 주의: 승인·배정·회수·취소·충전·지급·설정 저장은 누르는 즉시 운영에 반영됩니다. 확인창을 꼭 읽고 진행하세요.
화면 폭: 분석 4종(작업 27~30)과 순환 현황(작업 24)은 가로 1024px 이상에서만 열립니다. 좁은 화면에서는 상단 분석 메뉴 자체가 보이지 않습니다.

Ⅰ. 로그인과 대시보드

작업 1로그인하기

들어가는 길: 전기아저씨.com/admin
① 아이디 입력
② 비밀번호 입력 (두 값을 채워야 버튼 활성화)
③ 로그인 클릭
관제탑 대시보드가 열리면 성공.
공용 PC는 업무 후 우측 상단 로그아웃 필수. 비밀번호를 메모·메신저에 남기지 마세요.

작업 2대시보드 읽기

들어가는 길: 로그인 직후 (또는 상단 메뉴 → 대시보드)
① 배정 대기 카드 — 업무 시작 시 가장 먼저 확인. 누르면 아래 목록이 배정대기 탭으로 바로 전환됩니다. 붉은 긴급 미완료 숫자도 함께 확인
② 상태 탭 — 전체/배정대기/배정됨/진행중/완료·취소 (건수 표시)
③ 검색창 — 접수번호·이름·전화·내용으로 즉시 필터
목록은 자동 갱신됩니다. 빨간 배경(확인요망) 행이 보이면 최우선 처리 — 무응답 회수·후보 없음 등 자동배정이 처리하지 못한 건입니다. 확인요망 → 배정대기 → 나머지 순으로 맨 위에 자동 정렬되므로, 시각 정렬을 바꿔도 이 순서는 유지됩니다.

작업 3접수 찾기 (탭·검색)

들어가는 길: 대시보드
상태를 알면: 해당 상태 탭(작업 2의 ②) 클릭
특정 건을 찾을 때: 검색창(③)에 접수번호·고객명·전화번호·고장 내용 일부 입력 — 즉시 걸러집니다
시각 열 제목을 누르면 정렬 방향이 바뀝니다
원하는 행이 목록에 남으면 성공 — 행을 눌러 작업 4로.

작업 4접수 상세 열기

들어가는 길: 대시보드 목록
접수 행을 클릭 — 오른쪽에 요약 패널(상태·배정 이력 요약·설문 여부·추천 순위)이 열립니다
패널의 상세 열기를 클릭
"접수 #○○○○○○" 상세 화면이 열리면 성공.
배정만 하려면 상세를 열지 않아도 됩니다. 배정대기 건을 고르면 요약 패널에 후보 목록이 그대로 나오므로, 거기서 바로 배정을 눌러 처리할 수 있습니다(확인창은 작업 7과 같습니다).

Ⅱ. 접수와 배정

작업 5접수 상세 확인 (사진·음성·지도)

들어가는 길: 접수 상세 (작업 4)
위에서부터: 접수번호·긴급도·상태 배지 → 고장 내용 → 고객 첨부 사진(누르면 원본 크게) → 고객명·전화(누르면 전화 연결)·주소·접수 시각
음성 접수 건이면 사진 아래에 고객 음성 녹음 재생 + 자동 변환 텍스트가 표시됩니다
좌표가 있으면 지도에서 보기 링크로 위치 확인

작업 6배정 추천 순위 읽기

들어가는 길: 배정대기 접수 상세 → 아래로 스크롤
① 자동배정까지 남은 시간 — 접수 직후엔 이미 자동배정된 경우가 많고, 회수 후 배정대기로 돌아온 건은 여기 카운트다운이 표시됩니다
② 근거 순서 — 거절이력 → 지역 → 알 보유량 → 30일 배정 → 평균 별점 → 거리 순으로 줄 세운 결과입니다 (초긴급은 같은 시/군/구 우선)
③ 후보 카드의 배정 버튼 — 1순위엔 "자동배정 예정" 배지, 하위 후보엔 "알 보유량에서 뒤짐" 같은 순위 사유가 붙습니다
상세 원리는 「배정 로직 상세 문서」 참고. 알·거리·별점을 보고 관리자가 순위와 다르게 골라도 됩니다.

작업 7수동 배정하기

들어가는 길: 배정대기 접수 상세 → 추천 순위
배정할 후보 카드의 배정을 클릭
확인창(①)의 대상 이름을 꼭 읽고 — "○○(업체)에게 이 접수를 배정할까요? 배정 안내 문자가 발송됩니다."
② 배정으로 확정 (아니면 취소)
상태가 배정됨으로 바뀌고, 배정 이력에 "응답 대기 · 수동배정" 행이 생기면 성공 (위 그림). 업체가 수락/거절하면 이력에서 확인됩니다.

작업 8배정 회수하기

들어가는 길: 배정됨(응답 대기) 접수 상세
① "업체 응답 대기 중" 배너 확인 — 이 상태에서만 회수할 수 있습니다. 회수 전 배정 이력에서 현재 응답 상태를 한 번 보세요
② 배정 회수 클릭
확인창(①)을 읽고 ② 회수로 확정
접수가 배정대기로 돌아가면 성공. 회수한 대상은 이 접수의 자동 재선택에서 제외되고, 몇 분 안에 다음 순위에게 자동 배정됩니다 — 특정 업체에 주려면 회수 직후 바로 수동 배정하세요.

작업 9접수 취소하기

들어가는 길: 완료 전 접수 상세 → 화면 맨 아래
화면 맨 아래 접수 취소 클릭
확인창(①) "이 접수를 취소할까요?"에서 ② 접수 취소로 확정
상태 배지가 취소로 바뀌면 완료.
취소는 통계에 바로 반영됩니다 — 고객 요청 또는 명확한 오접수일 때만.
취소는 문자를 발송하지 않습니다. 배정 회수와 달리 수락·출동 중인 업체·전기기사에게도, 고객에게도 통지가 가지 않습니다. 이미 배정된 건을 취소했다면 곧바로 해당 업체에 전화로 알리세요 — 이미 현장으로 출발했을 수 있습니다.

작업 10만족도 조사 확인하기

들어가는 길: 완료된 접수 상세 → 아래로 스크롤
만족도 조사 구역에서 확인: 발송/미발송·제출/미참여 상태 → 별점 → 후기 → 고객 신고 지불 금액과 제출 시각
이 지불 금액이 정산 집계(작업 26)의 원천입니다. 고객 개인정보이니 화면 밖으로 유출 금지.

Ⅲ. 업체 관리

작업 11업체 가입 심사 — 승인

들어가는 길: 상단 메뉴 업체 관리 (숫자 배지 = 승인 대기 수)
업체 관리의 승인 대기 카드를 눌러 심사 화면으로 들어갑니다
⑤ 원본 크게 보기로 사업자등록증·전기공사업 등록증을 확인 — 등록증 상호와 신청 업체명 일치, 사업자번호 판독, 연락처·주소·서비스 지역 대조
문제 없으면 ⑥ 가입 승인 클릭
상태가 승인됨으로 바뀌면 완료 — 이제 그 업체는 로그인·배정 후보에 포함됩니다.
좌표가 없으면 "거리순 정렬은 안 되지만 지역 기준 자동배정은 동작" 안내가 뜹니다 — 정확한 거리 배정을 원하면 주소 입력 후 좌표 변환(작업 14).
좌표가 없는 업체를 승인하면 브라우저 확인창이 한 번 더 뜹니다 — "좌표가 없는 업체입니다 … 그래도 승인할까요?". 확인을 눌러야 승인됩니다.

작업 12업체 가입 거절하기

들어가는 길: 승인 대기 업체 상세 (작업 11과 동일 화면)
⑦ 거절 클릭 — 사유 입력 폼이 열립니다
거절 사유를 신청자가 이해할 수 있게 구체적으로 입력 (예: "전기공사업 등록증이 첨부되지 않았습니다. 두 증빙을 준비해 다시 신청해 주세요.")
거절 확정 클릭
목록 하단 "거절된 신청"에 사유와 함께 남으면 완료. 신청자는 로그인 시 사유를 확인하고 재신청할 수 있습니다.
사유는 비워도 거절됩니다(최대 200자). 하지만 신청자가 무엇을 고쳐야 할지 알 수 없으니 반드시 적으세요. 거절 버튼은 승인 대기 상태에서만 나타납니다.
거절한 신청은 다시 승인할 수 있습니다. 재신청을 기다릴 필요 없이 "거절된 신청" 카드를 눌러 상세로 들어간 뒤 가입 승인을 누르면 됩니다. 승인하면 거절 사유는 지워집니다.

작업 13업체 활성/비활성 전환

들어가는 길: 업체 관리 → 운영 중 테이블
⑦ 해당 업체 행 오른쪽의 활성 버튼 클릭
확인창의 전환 방향을 읽고 확정
배지가 활성↔비활성으로 바뀌면 완료. 비활성 = 계정 유지 + 배정 후보에서만 제외.
즉시 운영에 반영됩니다 — 실수로 눌렀다면 확인창에서 취소하세요. 확인창은 활성 → 비활성 전환에만 뜹니다. 비활성 → 활성은 확인창 없이 바로 반영되니 누르기 전에 대상을 확인하세요.

작업 14업체 정보 수정하기

들어가는 길: 업체 관리 → 업체명 클릭 → 상세 아래쪽
전화·주소·메모를 수정합니다 (아이디는 조회만, 비밀번호는 변경할 때만 새 값 입력)
주소를 바꿨으면 좌표 변환 클릭 — 위도·경도가 채워지는지 확인. 실패 시 "좌표를 직접 입력해 주세요" → 위도·경도 직접 입력
수정 저장 클릭 — 즉시 반영되고 자동으로 업체 관리 목록으로 돌아갑니다
목록 화면으로 돌아오면 저장된 것입니다. 같은 업체를 더 고칠 것이 있으면 다시 눌러 들어가세요.
좌표가 있어야 거리 기반 배정·거리 표시가 정확해집니다. 기존 업체 중 좌표 미등록이 많으니 틈틈이 채워 주세요. 주 1회는 업체·기사 목록을 훑어 좌표 없는 계정을 찾아 채우는 것을 정기 점검으로 삼으세요 — 좌표가 없으면 거리 단계에서 뒤로 밀리고, 거절이 나도 다음 후보로 자동 승계되지 않습니다.
서비스 가능 지역은 이 화면에서 바꿀 수 없습니다. 입력란 자체가 없습니다. 담당 지역 조정이 필요하면 업체가 직접 포털 → 내 정보에서 고치도록 안내하세요.

작업 15업체 직접 등록하기

들어가는 길: 업체 관리 → 우측 상단 + 직접 등록
②③ 추천인이 있으면 전화번호 입력 후 확인 조회 (선택)
④⑤ 로그인 아이디(중복 불가)·비밀번호(8자+) 입력
⑥⑦ 업체명·전화번호 입력, 이어서 주소 입력 → 좌표 변환 → 메모
맨 아래 업체 등록 클릭
운영 중 목록에 새 업체가 나타나면 완료 (직접 등록은 심사 없이 바로 승인 상태).
이 폼에는 사업자등록번호와 서비스 가능 지역 입력란이 없습니다. 그래서 직접 등록한 업체는 지역이 비어 전 지역 담당으로 동작하며 모든 지역 접수의 후보로 잡힙니다. 담당 지역을 좁히려면 업체가 로그인해 내 정보에서 등록해야 합니다. 아이디는 3자 이상이면 됩니다.

작업 16소개자 지정하기

들어가는 길: 업체(또는 기사) 상세 → 소개자 구역
지정(또는 변경)을 누르고 소개자 전화번호로 조회해 선택합니다 — 승인·활성 회원만 검색되고 본인은 지정할 수 없습니다
잘못 지정했으면 해제로 소개자를 지울 수 있습니다
소개자 이름이 표시되면 완료 — 이후 이 업체의 설문 실적에 따라 소개자에게 수수료가 적립됩니다.
"소급 지정 시 과거 조사는 적립되지 않습니다" — 지정 이후 실적부터만 적립됩니다.

Ⅳ. 전기기사 관리

작업 17기사 목록·근로확인 상태 보기

들어가는 길: 상단 메뉴 전기기사 관리
테이블에서 이름/근로 형태/아이디/전화/근로확인/상태를 확인합니다 (③④ 열 제목 클릭 = 정렬)
근로확인 열 읽기: 미작성 → 서명 전(배정 불가) → 서명 완료(배정 가능)
기사가 배정 후보가 되려면 승인 + 활성 + 서명 완료 세 가지가 모두 필요합니다. 전기기사는 가입 즉시 승인되므로 실질적인 관문은 서명 완료 하나입니다.
목록에 "확정 대기 (관리자 확인 필요)" 라벨이 준비돼 있지만, 기사가 서명하면 곧바로 서명 완료로 넘어가므로 실제로는 나타나지 않습니다.

작업 18기사 상세 확인하기

들어가는 길: 전기기사 관리 → 기사 이름 클릭
근로 형태·성명·전화·주소를 확인합니다 — 셀프 가입한 기사의 성명·전화는 휴대폰 본인인증으로 확인된 값입니다
근로확인 상태를 확인합니다 — 서명 완료여야 배정 후보에 들어갑니다(작업 19)
활동을 멈춰야 할 기사는 목록에서 활성 버튼으로 비활성 전환합니다
전기기사에게는 가입 심사 단계가 없습니다. 셀프 가입은 본인인증을 마치는 즉시 승인되어 자동 로그인되고, 관리자 직접 등록(작업 20)도 즉시 승인됩니다. 승인 대기 상태의 기사가 생기지 않으므로 승인 대기 카드에 기사가 나타나지 않고, 화면의 「가입 승인」·「거절」 버튼도 실제로는 쓰이지 않습니다(거절은 승인 대기 상태에서만 동작). 배정 가능 여부는 근로확인서 서명으로 갈리고, 활동 차단은 비활성으로 합니다.

작업 19근로확인서 확인·인쇄하기

들어가는 길: 기사 상세 → 근로확인서 열기 (⑤)
기사 서명 이미지·서명 시각 확인
계약기간·근무장소·업무 내용·근무일·소정근로시간·주휴일 확인
⑥⑦⑧ 임금 형태(월급/일급/시급)·금액·상여·기타, 4대보험 체크, 임금지급일·지급방법 확인·보정 → 임금 저장 ("저장했습니다" 확인)
인쇄 화면에서 브라우저 인쇄로 출력하거나 PDF로 저장
기사가 서명을 완료하면 전 항목 읽기 전용 — 저장을 시도하면 "전기기사가 서명 완료한 근로확인서는 수정할 수 없습니다"로 거부됩니다. 사업주 정보는 설정(작업 32)에서 자동 기입됩니다.
보정할 시간이 거의 없습니다. 기사는 가입 직후 설정의 기본 임금이 채워진 상태로 곧바로 서명할 수 있습니다. 개별 조건을 협의할 기사에게는 서명 전에 미리 연락해 대기시킨 뒤 임금을 입력하세요.

작업 20기사 직접 등록하기

들어가는 길: 전기기사 관리 → + 직접 등록
②③ 추천인(선택) → ④⑤ 아이디·비밀번호 → ⑥⑦ 근로 형태(일일/상시) 선택
성명·전화·주소·좌표·메모 입력 → 전기기사 등록
목록에 미작성 상태로 나타나면 완료 — 등록 즉시 승인 상태이고, 기사가 로그인해 서명해야 배정 가능이 됩니다.
직접 등록은 휴대폰 본인인증을 거치지 않습니다. 본인인증 관문은 셀프 가입에만 있습니다. 여기서 입력한 성명·전화번호는 확인되지 않은 값이므로, 신분증과 자격을 별도로 확인한 뒤에만 등록하세요. 서비스 가능 지역 입력란도 없어 전 지역 담당으로 시작합니다.

Ⅴ. 알 크레딧

작업 22알 충전하기

② 충전 사유 입력 — 어떤 입금 건인지 알 수 있게 (예: "8/31 무통장 입금 3알 확인"). 사유를 넣어야 버튼이 활성화됩니다

작업 24순환 현황 조회하기

① 시/도(필요 시 시/군/구까지) 선택
② 순위표 읽기 — 순위·이름·종류·알 보유·30일 배정·평균 별점·후기 수. 이 순서가 그 지역의 자동배정 예상 순번입니다
동률은 거리로 갈릴 수 있고, 초긴급은 같은구·거리 우선이라 이 순번을 그대로 쓰지 않습니다. 확인용 화면이며 편집 불가 — 순위에 영향을 주려면 알 충전(작업 22)이나 활성 상태를 조정하세요. 서비스 가능 지역은 관리자가 바꿀 수 없으므로 업체에 직접 수정을 요청해야 합니다.

작업 25소개 수수료 확인·지급하기

들어가는 길: 상단 메뉴 정산 · 실제 이체 확인 후에만 지급!
소개자 행 클릭 → 건별 내역 펼침 (소개대상·유형·결제금액·수수료·상태·적립일·후기)
⑤ 적립 월 필터로 좁히고, ⑥ CSV로 내려받아 이체 자료와 대조
일부 지급이면 체크박스 선택 후 ⑦ 선택 지급, 전액이면 ⑧ 전액 지급 완료 → 확인창의 소개자명·금액 재확인 후 확정
미지급 합계가 줄고 지급 누계가 늘면 완료.
지급 완료는 회계 상태를 바꿉니다 — 실제 이체 전에 누르지 마세요.
건별 내역에서 결제 금액이 100만원 이상이면 「고액」 배지가 붙습니다 — 설문 원본과 금액을 한 번 더 대조하세요. 소개자 이름 옆의 「비활성」 배지는 그 계정이 현재 비활성이라는 뜻이며, 이미 적립된 수수료는 그대로 지급합니다.
확인창 문구는 선택 지급이면 "선택한 N건을 지급 완료로 처리할까요?", 전액이면 "○○의 미지급 N원 전액을 지급 완료로 처리할까요?"입니다.

작업 26정산 집계 조회·CSV 내보내기

들어가는 길: 상단 메뉴 정산 집계
② 정산 월 선택 — 업체·전기기사별 집계 테이블 갱신 (해당 월 설문 제출이 없으면 "집계 데이터 없음")
열 읽기: 고객 신고 총수금액 · 완료 · 집계 · 미입력 · 커버리지(완료 중 금액 입력 비율). ④ 물음표로 산식 확인
「완료」는 그 달에 고객이 제출한 만족도 조사 건수입니다 — 접수가 완료된 달이 아니라 조사가 제출된 달로 갈립니다. 조사에 응답하지 않은 완료 건은 이 숫자에 들어가지 않습니다
③ CSV 내보내기로 내려받아 엑셀에서 이어서 작업
이 금액은 고객 신고 기준 참고치 — 세무·회계 확정치가 아닙니다. 공식 정산은 원장·이체 내역과 함께.
지난달 완료 건이라도 고객이 이번 달에 조사를 제출하면 이번 달 집계에 잡힙니다. 월별 합계가 완료 건수와 맞지 않는 것은 정상입니다.

작업 32근로확인서 기본값·서명 설정하기
