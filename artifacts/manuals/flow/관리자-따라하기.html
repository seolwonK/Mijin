읽는 방법

먼저 들어가는 길을 따라 화면을 엽니다. 번호가 표시된 사진은 바로 아래 설명과 같은 위치를 가리킵니다. 입력·저장·상태 변경은 실제 처리할 대상과 내용을 확인한 뒤 진행합니다.

라이브 고객·업무 정보가 포함될 수 있으므로 내부 교육과 운영 목적으로 사용합니다. 계정의 비밀번호와 개인 인증 정보는 이 문서에 싣지 않습니다.

따라하기 01

관리자 로그인

들어가는 길 /admin/login

  1. 관리자 아이디와 비밀번호를 입력하고 로그인 버튼을 누릅니다. 비밀번호 옆 표시 버튼으로 입력을 확인할 수 있습니다.
  2. 로그인 후 접수 관리 화면과 왼쪽 업무 메뉴가 보이는지 확인합니다.
  3. 업무를 마치면 왼쪽 아래 로그아웃을 누릅니다. 모바일에서는 메뉴를 먼저 엽니다.

함께 확인하세요

  • 로그인 오류가 나면 아이디·비밀번호를 확인합니다. 세션이 만료되면 다시 로그인한 뒤 원래 화면으로 돌아갑니다.
따라하기 02

업무 메뉴와 열린 화면 탭

들어가는 길 /admin

  1. 왼쪽 업무 메뉴에서 접수 운영, 파트너 관리, 정산, 분석, 시스템을 펼칩니다. 메뉴 검색에 화면 이름을 입력해 빠르게 찾을 수 있습니다.
  2. 메뉴를 누르면 상단에 해당 화면 탭이 열립니다. 탭을 눌러 이미 열었던 화면으로 돌아가고, ×로 필요 없는 탭을 닫습니다.
  3. 가로 공간이 부족하면 메뉴를 접습니다. 휴대폰에서는 상단 메뉴 버튼으로 서랍을 연 뒤 같은 업무 메뉴를 선택합니다.

함께 확인하세요

  • 열린 탭은 화면 이동을 돕는 기능입니다. 입력 중인 폼의 모든 값을 자동 저장하는 기능은 아니므로 저장 여부를 확인하고 이동합니다.
  • 분석 4종, 순환 현황, 정산 집계는 모바일에서도 조회할 수 있습니다. 구판의 “1024px 이상에서만 이용” 안내는 적용되지 않습니다.

따라하기 03

접수 관리: 요약과 목록

들어가는 길 /admin

  1. 관리자 확인, 배정 대기, 진행 중, 긴급 미완료 수치를 확인합니다. 각 항목의 전체 기준·조회된 접수 기준 표기를 함께 읽습니다.
  2. 배정대기·배정됨·진행중·완료·취소 등 필요한 상태 필터를 누릅니다. 관리자 확인 카드는 확인이 필요한 접수를 모아 보여줍니다.
  3. 접수 검색에 접수번호·고객·주소·고장 내용을 입력하고, 접수 정렬에서 처리 우선순·오래된 순·최근 순을 선택합니다.
  4. 긴 고장 설명은 내용 펼치기로 확인합니다. 이전·다음으로 목록 페이지를 이동합니다.

함께 확인하세요

  • 접수 목록의 조회 범위는 최근 최대 200건입니다. 목록 안의 건수와 전체 기간 요약 숫자가 다를 수 있습니다.
  • 긴급 미완료는 분석 현황의 현재 남은 업무로 연결됩니다. 취소·완료된 접수를 현재 처리 대기와 혼동하지 않습니다.
따라하기 04

접수 선택과 상세 확인

들어가는 길 대시보드 → 접수 선택 → 상세 열기

  1. 접수를 선택하면 큰 화면에서는 오른쪽 패널, 작은 화면에서는 상세 서랍이 열립니다.
  2. 접수 상태·고장 내용·고객 연락처·주소·배정 정보를 확인합니다. 긴 내용을 확인해야 하면 상세 열기로 이동합니다.
  3. 첨부 사진을 눌러 크게 확인합니다. 음성 접수라면 녹음과 변환 텍스트를 확인합니다. 지도 링크는 좌표가 있을 때 제공됩니다.
  4. 배정 이력에서 제안·수락·거절·회수 여부를 확인하고, 완료 건은 만족도 조사 응답도 확인합니다.

함께 확인하세요

  • 고객 연락처와 주소가 포함된 화면입니다. 이 매뉴얼의 라이브 캡처는 내부 운영 용도로 취급합니다.
따라하기 05

추천 후보 확인과 수동 배정

들어가는 길 배정대기 접수 → 배정 후보

  1. 접수가 배정대기인지 확인하고 후보의 업체·기사 구분, 담당 지역, 알, 배정 횟수, 평점, 거리를 비교합니다.
  2. 일반·긴급과 초긴급의 순위 기준을 구분합니다. 초긴급은 소재지가 같은 시군구인 후보를 먼저 비교합니다.
  3. 대상을 골라 배정을 누릅니다. 확인창의 대상과 안내 문자 발송 내용을 읽은 뒤 실제 업무에서 배정을 확정합니다.
  4. 배정됨 상태와 배정 이력의 응답 대기를 확인합니다. 상대가 응답하지 않으면 10분 기준으로 다음 후보로 넘어갈 수 있습니다.

함께 확인하세요

  • 같은 접수의 거절·무응답 회수·관리자 회수 이력은 해당 후보를 후순위로 보냅니다. 상세한 비교 순서는 배정 로직 상세 문서를 참조합니다.
  • 지도·순환 현황의 참고 수치만으로 실제 접수의 1순위를 단정하지 않습니다. 현장 위치와 이력을 포함하는 접수별 후보가 기준입니다.
따라하기 06

배정 회수와 접수 취소

들어가는 길 접수 상세

  1. 잘못 배정했거나 담당 변경이 필요하면 현재 배정과 이력을 확인하고 회수 버튼을 누릅니다.
  2. 확인창에서 대상을 확인한 뒤 실제 업무에서 회수를 확정합니다. 접수가 다시 배정대기가 되었는지 확인합니다.
  3. 접수 자체를 종료해야 하면 접수 취소를 선택하고 사유를 입력해 확정합니다. 배정만 바꾸려는 경우에는 접수 취소와 구분합니다.
  4. 고객에게 필요한 변경 사항은 별도로 안내하고, 접수·배정 상태와 기록을 다시 확인합니다.

함께 확인하세요

  • 회수와 취소는 실제 업무 상태를 바꿉니다. 촬영을 위해 운영 접수를 변경하지 않았으며, 화면에 해당 상태가 있는 경우에만 버튼이 나타납니다.
  • 접수 취소 시 고객에게 자동 취소 문자가 발송되는 것으로 가정하지 말고 직접 연락합니다.
따라하기 07

업체 목록, 심사, 정보 수정

들어가는 길 파트너 관리 → 업체 관리

  1. 업체 목록에서 승인 상태·활성 여부를 확인하고 대상 업체를 엽니다.
  2. 가입 심사에서는 사업자 정보와 첨부 증빙을 확인합니다. 승인하거나, 보완이 필요하면 거절 사유를 작성합니다.
  3. 상세 화면에서 업체명·연락처·주소·메모를 수정한 뒤 저장합니다. 주소를 바꿨다면 좌표 변환 결과도 확인합니다.
  4. 활성 여부를 변경할 때는 현재 처리 중인 건과 담당 가능 여부를 확인합니다. 승인 거절한 신청을 다시 심사할 때도 기존 사유와 서류를 확인합니다.

함께 확인하세요

  • 승인 상태와 활성 여부는 서로 다릅니다. 승인된 업체라도 비활성이면 자동배정 후보에서 제외됩니다.
  • 서비스 가능 지역은 업체 본인이 포털의 내 정보에서 변경합니다. 관리자 정보 수정 폼에는 서비스 지역 편집 칸이 없습니다.
  • 비밀번호 재설정은 새 비밀번호 칸에 입력한 뒤 저장합니다. 비워 두면 기존 비밀번호가 유지됩니다.
  • 사업자 증빙, 전화번호, 주소는 해당 업무를 처리할 때만 열람합니다.
따라하기 08

소개자 지정·변경·해제

들어가는 길 업체 또는 기사 상세 → 소개자

  1. 현재 소개자와 업체·기사 구분을 확인합니다. 지정된 소개자가 없으면 지정, 이미 있으면 변경을 누릅니다.
  2. 전화번호로 조회한 목록에서 이름과 구분을 확인합니다. 올바른 대상을 선택하면 바로 반영되므로 선택 전에 다시 확인합니다.
  3. 선택을 그만두려면 취소를 누릅니다. 기존 소개자를 없애려면 해제를 누르고 지정된 소개자 없음으로 바뀌었는지 확인합니다.

함께 확인하세요

  • 소개자를 나중에 지정해도 이미 제출한 과거 설문의 수수료는 소급 적립되지 않습니다.
  • 가입 시 본인 추천으로 지정할 수 없습니다. 대상 조회가 실패하면 다시 조회한 뒤 선택합니다.
따라하기 09

업체·기사 직접 등록

들어가는 길 파트너 관리 → 업체 관리 또는 전기기사 관리 → 등록

  1. 업체 등록 또는 전기기사 등록 화면에서 계정 정보와 이름·연락처·주소를 입력합니다.
  2. 주소와 좌표 변환 결과, 업체·기사별 필수 항목을 확인합니다. 서비스 가능 지역은 등록 후 해당 계정의 포털 내 정보에서 설정합니다.
  3. 저장 후 목록과 상세에서 계정 정보·승인·활성 상태를 확인합니다. 기사에게는 근로확인서 작성 경로도 안내합니다.

함께 확인하세요

  • 직접 등록은 실제 계정을 만듭니다. 설명용 화면에는 입력 위치만 표시하며, 촬영을 위해 운영 계정을 추가하지 않습니다.
따라하기 10

기사 정보와 근로확인서

들어가는 길 파트너 관리 → 전기기사 관리

  1. 목록에서 기사 정보와 근로확인서 상태를 확인하고 상세 화면을 엽니다.
  2. 기사의 연락처·주소·활성 상태를 확인합니다. 서비스 가능 지역은 기사 본인이 내 정보에서 설정합니다. 가입은 즉시 승인되지만 배정에는 근로확인서 서명 완료가 필요합니다.
  3. 근로확인서에서 실제 협의한 근무조건과 임금을 확인합니다. 서명 전 문서의 임금을 정정한 뒤 임금 저장을 누릅니다. 서명 완료본은 수정할 수 없습니다.
  4. 확인서 인쇄 기능으로 인쇄하거나 브라우저에서 PDF로 저장합니다.

함께 확인하세요

  • 서명 완료 조건을 충족하지 않은 기사는 배정 후보에 포함되지 않습니다. 미서명과 비활성은 서로 다른 제외 사유입니다.
  • 서명 완료본을 임의로 수정하도록 안내하지 않습니다. 정정이 필요하면 당사자와 확인 후 정해진 관리자 절차로 처리합니다.
따라하기 11

입금 확인 후 알 충전·정정

들어가는 길 업체 또는 기사 상세 → 알 크레딧

  1. 입금자, 실제 입금액, 충전 대상 업체·기사를 확인합니다.
  2. 충전 수량을 최소 30알, 30알 단위로 입력합니다. 30알은 30,000원, 60알은 60,000원입니다.
  3. 충전 사유를 기록하고 입금 확인이 끝난 건에 한해 충전을 실행합니다. 잔액과 변동 이력을 확인합니다.
  4. 오입력 정정은 증감 수량과 사유를 입력합니다. 정정은 충전과 구분되며 잔액을 음수로 만들 수 없습니다.

함께 확인하세요

  • 업체·기사의 알 충전하기 화면은 수량·금액·계좌 안내입니다. 자동 결제나 입금 자동 확인 기능으로 안내하지 않습니다.
  • 배정을 수락할 때 잔액이 있으면 1알 차감됩니다. 0알이어도 수락할 수 있으며 음수로 차감되지 않습니다.

순환 현황에서 지역별 후보 비교

들어가는 길 접수 운영 → 순환 현황

  1. 전국 배정 대상 요약과 지역별 후보 수를 확인합니다. 기본으로 선택된 지역을 확인하고 원하는 시도·시군구로 바꿉니다.
  2. 선택 지역의 1순위 후보와 전체 순위를 확인합니다. 업체·전기기사 필터 또는 후보 이름 검색으로 좁힙니다.
  3. 알 보유, 최근 30일 배정, 평점·후기를 비교합니다. 검색·필터를 사용해도 원래 순번은 유지됩니다.
  4. 상세 링크로 업체·기사 관리 화면을 엽니다. 다음 페이지의 후보도 확인할 수 있습니다.

함께 확인하세요

  • 순환 화면은 일반·긴급의 참고 순위입니다. 실제 접수에서는 현장 거리, 초긴급의 같은 시군구 여부, 해당 접수의 거절·회수 이력이 추가로 반영됩니다.
  • 지역 후보 수는 중복 대상의 단순 합계가 아닙니다. 같은 업체·기사가 여러 지역을 담당할 수 있습니다.

소개 수수료 조회와 지급 처리

  2. 수수료가 발생한 작업과 고객 신고 금액 등 근거를 확인합니다.
  3. 실제 송금 확인 후 지급 대상 항목을 선택하고 지급 처리를 확정합니다. 지급 후 상태와 기록을 확인합니다.

함께 확인하세요

  • 소개 수수료는 고객이 만족도 설문에 입력한 작업 금액을 근거로 3%가 적립됩니다. 실제 업체 계좌 입금을 자동 조회하는 구조가 아닙니다.
  • 지급 완료 상태 변경은 실제 송금을 수행하는 기능과 구분합니다.

월별 정산 집계와 신고 원본

들어가는 길 정산 → 정산 집계

  1. 집계 월을 선택하고 업체·기사별 고객 신고 금액을 확인합니다.
  2. 대상 이름 또는 금액을 눌러 신고 내역을 엽니다.
  3. 접수번호, 고장 내용, 고객, 주소, 신고 금액, 응답일을 대조합니다. 금액 미입력과 0원은 구분합니다.
  4. 내역이 많으면 다음 페이지로 이동합니다. 접수번호로 상세를 열거나 CSV로 내보내 후속 업무에 활용합니다.

함께 확인하세요

  • 월 집계는 설문 응답일의 한국 시간 기준입니다. 실제 작업일·접수일·입금일 기준 집계와 다를 수 있습니다.
  • 고객 신고액을 실제 입금액이나 회계 확정액으로 단정하지 않습니다.

분석 현황의 숫자 읽기

들어가는 길 분석 → 현황

  1. 지금 남은 업무는 전체 기간의 현재 미완료 접수입니다. 배정 대기·수락 대기·출동·작업 중 숫자로 운영 큐에 이동할 수 있습니다.
  2. 오늘·최근 7일·최근 30일을 선택하고 표시된 시작일·종료일을 확인합니다.
  3. 새 접수, 작업 완료, 담당자 수락 비율과 각 설명을 확인합니다. 일별 차트에서 날짜를 누르거나 날짜별 수치 보기를 펼칩니다.
  4. 고객이 신고한 작업 금액, 금액 입력 설문 수, 건당 평균을 확인합니다. 월별 금액과 신고 원본 보기로 정산 집계에 이동합니다.

함께 확인하세요

  • 새 접수는 접수일 기준이며 이후 취소된 건도 포함합니다. 완료는 완료일 기준이므로 두 숫자로 완료율을 만들면 안 됩니다.
  • 담당자 수락 비율은 선택 기간 접수 중 수락된 배정 이력이 있는 접수의 비율입니다. 분모가 없으면 집계 없음으로 표시됩니다.
  • 신고 금액은 선택 기간에 제출된 설문 기준입니다. 0원은 포함하고 금액 미입력은 제외합니다.

지도에서 접수 지역과 담당 등록 확인

들어가는 길 분석 → 지도

  1. 최근 30일의 집계 범위와 지역 확인된 접수 수를 확인합니다.
  2. 지역별 접수는 접수 많은 순입니다. 접수 있는 지역·전체·담당 등록 없음 필터와 지역 이름 검색을 사용합니다.
  3. 지도 색상의 건수 범위를 읽고 지역을 누릅니다. 시도를 선택하면 시군구별로 확인할 수 있습니다.
  4. 시군구 목록에서 배정 후보 보기로 순환 현황에 이동합니다. 전국 보기로 돌아갑니다. 모바일은 지역 목록이 지도보다 먼저 표시됩니다.

함께 확인하세요

  • 지도 접수는 최근 30일 접수일 기준이며 취소를 제외합니다. 현황의 새 접수와 취소 포함 기준이 다릅니다.
  • 담당 등록은 활성·승인 업체와 기사의 명시적 담당 지역 등록 수입니다. 즉시 출동 가능한 인원이나 실제 배정 후보 수와 같지 않습니다.
  • 여러 지역 등록은 중복될 수 있어 지역별 등록 수를 더해 전국 인원으로 사용하지 않습니다. 지역 미확인 건은 별도 안내를 읽습니다.

전체 설문과 고객 입력 금액

들어가는 길 분석 → 설문

  1. 전체 기간 요약에서 전체 설문, 응답 완료, 미응답, 고객 입력 금액 합계를 확인합니다.
  2. 전체·응답 완료·미응답을 선택하고, 접수번호·고객명·전화번호로 검색합니다.
  3. 설문별 고객 입력 금액과 평점을 확인합니다. 미응답의 —, 응답했지만 금액 미입력, 실제 0원을 구분합니다.
  4. 미응답 건의 설문 재발송을 누르면 수신 고객·전화번호·접수번호가 담긴 확인창이 열립니다. 실제 재안내가 필요한 고객인지 확인 후 재발송합니다.
  5. 발송 요청 완료·발송 실패·발송 확인 중 상태를 확인합니다. 방금 발송한 건은 1분 후 다시 요청할 수 있습니다.

함께 확인하세요

  • 재발송은 기존 설문 링크를 사용합니다. 이미 응답한 설문은 다시 발송할 수 없습니다.
  • 발송 요청 완료는 통신사 최종 수신 확인을 뜻하지 않습니다. 발송 실패는 서비스 설정·잔액을 확인하고 필요하면 고객에게 전화로 안내합니다.

업체·기사 평점 분석

자동배정·근로조건·충전 계좌 설정

  1. 자동배정 활성 여부와 배정 대기 관련 설정을 확인합니다. 실제 운영 정책에 맞는 값을 입력한 뒤 해당 저장 버튼을 누릅니다.
  2. 사업주 정보와 근로확인서 기본값·서명을 확인합니다. 기본값 변경과 이미 서명한 문서의 내용은 구분합니다.

함께 확인하세요

일일 운영 순서와 문제 대응

들어가는 길 관리자 업무 전반

  1. 업무 시작: 관리자 확인·긴급 미완료 → 배정 대기 → 진행 중 순으로 확인합니다. 후보가 없으면 서비스 지역·활성·승인·기사 서명 상태를 확인합니다.
  2. 업무 중: 응답 대기 10분과 회수 이력을 확인하고, 고객·담당자 연락 내용을 기록합니다. 지도상의 등록 수만으로 배정을 확정하지 않습니다.
  3. 정산 업무: 고객 신고 원본과 실제 입금 근거를 대조한 뒤 알 충전·수수료 지급을 처리합니다.
  4. 후속 관리: 설문 미응답과 발송 실패를 확인하고 필요한 고객에게 재안내합니다.
  5. 업무 종료: 저장·처리 결과를 확인하고 공용 기기에서 로그아웃합니다.

함께 확인하세요

  • 숫자가 갱신되지 않으면 새로고침합니다. 오류 안내가 남으면 마지막 조회 결과인지 확인한 뒤 재시도합니다.
  • 배포·계정·문자 발송 장애와 고객의 실제 처리 상태를 구분해 대응합니다.
